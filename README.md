# Peak Distance

**查过的词，和原句一起留下。**

Peak Distance 是一款浏览器语言学习扩展。读网页、刷 X 或看 YouTube 时，你可以查词、翻译，再把想记住的表达连同原句保存下来。复习时回到它出现过的地方，也可以把学习记录存成本地文件，用 Obsidian 等笔记软件继续整理。

它支持英语之外的多种语言。你可以选择译文和解释使用的语言，再按语言筛选生词本。

## 安装

需要桌面 **Chrome 142 或更新版本**。当前发布版为 [v0.5.2](https://github.com/Rayyy3320/peak-distance/releases/tag/v0.5.2)。

1. 从 [Releases](https://github.com/Rayyy3320/peak-distance/releases/latest) 下载名称以 `-chrome.zip` 结尾的安装包，解压到一个固定文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。

无需安装 Node.js，也无需运行命令。安装后将 Peak Distance 固定到工具栏，刷新已打开的网页，就可以选词试用了。请保留解压后的文件夹，扩展运行时仍要读取它。

<details>
<summary>从源码构建</summary>

准备 Node.js 22+ 和 npm，下载源码后，在项目目录运行：

```sh
npm ci
npm run build
```

然后按上面的步骤加载 `.output/chrome-mv3`。开发时可用 `npm run dev`，检查改动可用 `npm run verify-local`。重新构建后，还需要重新加载扩展并刷新目标网页。

</details>

## 使用

### 读网页：查词，也保存原句

选中单词或短语，点击「查词」；选中句子或段落，点击「翻译」。保存表达时，原句和来源也会一起留下。

例如，读到 “She is comfortable **with** people.”，保存 **with** 后，复习时还能看到这句原文，不用只对着一个孤立的词回想。

选区旁的「添加到对话」可以把内容带入 AI 问答。单词和短语会连同所在原句一起附加；选择句子或段落时，则附加选中的内容。已有的问题不会被替换，点击发送后才会请求 AI。

### 看视频：保留原文，按句回听

打开带字幕的 YouTube 视频，在视频下方阅读双语字幕。扩展沿用当前的原文字幕轨道；译文用什么语言，由你的设置决定。

悬停字幕中的词语，可以查看释义并暂停播放；点击后展开词卡，也能拖选短语、收藏整句。播放器字幕和学习面板里的字幕选区，都可以添加到对话中继续提问。

播放器底部的「双语 → 原文语言」可以选择视频提供的字幕轨道，也可以通过 YouTube 原生「设置 → Subtitles/CC」切换。菜单还可以调整翻译方式、译文显示和字号。打开 **AP** 后，视频会在每句字幕结束时暂停；学习面板也提供上一句、重播和下一句，方便反复听一段内容。

### 学不同语言：选择自己看得懂的解释

在「设置 → 语言」中选择默认的「理解语言」，也就是你希望译文和词语解释使用的语言。还可以单独设置某种原文语言，例如用中文理解英语、用英语理解日语。

网页和视频中的表达进入同一本生词本。点击生词本顶部的语言筛选按钮，可以只看某种语言的记录，再调整「已收藏／在学／已掌握」状态，或进入原句复习。

不同语言能使用的查询来源不同。英语到中文优先查询在线词典，其他语言组合可能使用常规译文。词卡会区分来源；语言无法确认时会标为「待确认」，不会把所有内容都当作英语。

### 留在本地：把学习记录放进自己的文件夹

在「设置 → 学习库」点击「连接学习文件夹」，选择一个本地目录。词汇、句子、笔记、语言偏好和已保存的完整聊天历史，会以 Markdown 格式保存，也就是能用文本编辑器打开的笔记文件。你也可以选择 Obsidian 仓库中的文件夹。

在 Obsidian 中修改词条状态或「我的笔记」，扩展会读回这些变化。同一台电脑上的 Chrome 和 Edge 连接同一个目录后，可以共享学习记录；两边同时修改同一字段时，会保留双方内容并提示冲突。

词语统一保存在「生词本.md」，句子统一保存在「句子.md」，每条记录占一个小节；AI 对话仍按会话保存。完整释义、视频位置等恢复数据放在 `.peak-distance` 辅助目录，迁移旧散文件时也会在这里保留备份。请保留整个学习文件夹。

两边都更新扩展后，分别连接同一个文件夹并点击「立即同步」。同步会写入本机修改，再读回另一浏览器已写入的内容；切回浏览器时也会读取共享文件。权限不足、文件损坏或冲突会明确提示，未提交内容保留在本机。

不连接文件夹也能使用，记录仍保存在浏览器扩展中。断开学习库不会删除已有文件，API Key 和 AI 服务配置也不会写入学习库。

### 使用 AI：带着原文问清楚

在「设置 → AI 服务」中选择服务商，填写自己的 API Key，点击「保存并使用」。预设包括 DeepSeek、OpenAI、Anthropic、Gemini、智谱 GLM 和 Kimi；其他兼容服务可在高级设置中填写地址、模型和接口格式。

你可以直接提问，也可以附加页面、选区或字幕。材料会显示在输入框上方，点开能查看完整内容，移除材料不会删掉已输入的问题。词卡里的「继续问」也会先带入表达和原句，再由你决定是否发送。

**常规查词和翻译无需 API Key。** 配置 Key 后不会自动切换为 AI 翻译。若另外开启「无词典结果时自动使用 AI 查词」，只有主动查词、没有适用词典或词典明确无结果，并且 AI 已配置时，才会尝试 AI 解释。悬停预览不会触发这一功能，词典网络故障也不会触发它。

## 隐私与服务

- 学习记录默认保存在本机扩展中；连接学习库后，通过本地文件夹共享。扩展不提供账号或内置云同步。
- API Key 和 AI 服务配置只保存在当前浏览器，不写入 Markdown 学习库。使用同一学习库的另一浏览器，需要自行配置 AI 服务。
- 联网查词或翻译时，所需文本会发送给对应服务；使用 AI 时，会发送问题及所附材料。服务可用性、模型权限和费用取决于你的配置与供应商。
- 原句复习读取已有记录，不发起 AI 请求。

## 常见问题

**未发送的内容会一直保存吗？**

不会。切换固定侧栏和浮动面板时，输入、材料和引用会保留；关闭面板或切换会话后，未发送的内容会丢弃。新对话在首次发送后才进入历史记录，临时输入不会写入学习库。

**为什么有时查不到释义或译文？**

不同语言的词典覆盖范围不同，翻译服务也可能受网络或限流影响。可以重试、换来源，或按需使用 AI。查询失败不会阻止你保存表达与原句。

**支持没有字幕的视频吗？**

目前依赖 YouTube 已有字幕，不采集音频，也不为无字幕视频生成字幕。暂不支持 Shorts、直播或 Netflix。

**如何更新？**

将新版安装包解压到原安装目录并替换文件，在 `chrome://extensions` 中点击 Peak Distance 的「重新加载」，再刷新使用扩展的网页。不要先卸载扩展，卸载会删除浏览器中的本机扩展数据。

**安装后为什么没有查词入口？**

先刷新网页，再检查扩展的「网站访问」是否允许当前站点。

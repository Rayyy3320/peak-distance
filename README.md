# Peak Distance

**在网页与视频里读懂英文，把值得记住的表达连同语境留下来。**

Peak Distance 是一款 Chrome 英语学习扩展。浏览网页、阅读 X 或观看 YouTube 时，就地查词、翻译、收藏，再回到原句复习。

[安装](#安装) · [使用](#使用) · [隐私与服务](#隐私与服务) · [常见问题](#常见问题)

- **就地理解**：选词查释义，选句或段落看翻译，保留词典来源。
- **视频精读**：双语字幕、悬停查词、逐句回听，以及可选的句末自动暂停。
- **带着语境记忆**：网页与视频共用生词本，收藏时保留原句、来源和视频位置。
- **按需深入**：用 AI 解释用法，或附加页面、选区、字幕继续提问。

## 安装

需要桌面 **Chrome 142 或更新版本**。

### 使用安装包

从 [最新版本](https://github.com/Rayyy3320/peak-distance/releases/latest) 下载 `peak-distance-<版本>-chrome.zip` 安装包，**无需安装 Node.js，也无需运行命令**。

1. **解压**到一个固定文件夹，例如 `PeakDistance`；打开后应能直接看到 `manifest.json`。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角的「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择刚才包含 `manifest.json` 的文件夹。

安装后，在浏览器的扩展菜单中将 **Peak Distance** 固定到工具栏，刷新已打开的网页即可使用。请保留安装文件夹，扩展运行时仍需读取其中的文件。

<details>
<summary>从源码构建（开发者）</summary>

准备 Node.js 22+ 和 npm，下载源码并在项目目录运行：

```sh
npm ci
npm run build
```

按上面的步骤加载 `.output/chrome-mv3` 文件夹。`npm run zip` 可生成用于分发的 Chrome 安装包。

日常开发使用 `npm run dev`，提交改动前可运行 `npm run verify-local`。修改代码并重新构建后，需要重新加载扩展并刷新目标网页。

</details>

## 使用

### 读网页

选中英文单词，点击「查词」，查看释义、例句和词典来源；选中句子或段落，点击「翻译」。值得记住的表达可以直接收藏。

例如，读到 “She is comfortable **with** people.”，选中 **with** 查词并保存，生词本会同时保留这句原文。

### 看视频

打开带英文字幕的 YouTube 视频，在视频下方阅读双语字幕。悬停词语可查词并暂停，点击展开词卡；支持拖选短语、收藏词语和整句。

播放器底部的「双语」菜单可调整翻译方式、中文显示、字号，以及 **AP（每句结束自动暂停）**。打开学习面板后，还能查看字幕列表、词语出现位置和已保存内容，逐句重播。

### 回看与复习

点击工具栏中的 Peak Distance，进入「生词本」。在原句中回顾表达，调整「已收藏／在学／已掌握」状态，或返回网页与视频中的原始位置。再次遇见已存词语时，网页和字幕会共享学习标记。

工作区可切换为固定侧栏或浮动面板，会话及未发送输入、材料与引用会随之保留；关闭面板或切换会话后丢弃未发送内容，首次发送才保存到历史。

### 使用 AI（可选）

在「设置 → AI 服务」选择服务商，填写 **API Key**，点击「保存并使用」。预设支持 DeepSeek、OpenAI、Anthropic、Gemini、智谱 GLM 和 Kimi，自带地址与默认模型；原 DeepSeek Key 可继续使用。

其他兼容服务选择「自定义服务」，在「高级设置」填写接口格式、HTTPS API 地址和模型 ID。支持 OpenAI Chat Completions、Anthropic Messages、Gemini 原生协议；高级设置也可调整预设服务的地区地址或账户可用模型。保存新地址时，按浏览器提示允许访问该 API 域名。

问答可以直接提问，也可以通过「附加材料」加入页面、选区或视频字幕。点击「继续问」只会先带入材料，发送后才请求 AI。

**查词与常规翻译无需 key。配置 key 不会自动启用 AI 翻译。**

## 隐私与服务

- 生词、原句、学习状态和聊天记录保存在本机扩展中，不提供账号或云同步。
- 查词使用有道、剑桥英汉；常规字幕翻译优先使用可用中文字幕、平台翻译，再尝试 Google 免费翻译。
- 联网查询会向对应服务发送所需文本；AI 请求会发送问题及所附材料。各服务的 API Key 保存在本机扩展设置中，宿主网页无法读取。切换服务后，新请求使用新配置，已开始的问答继续使用发起时的配置。
- AI 仅在主动使用相关功能或选择 AI 翻译模式时调用；普通查询失败不会自动转为 AI。原句复习使用已保存数据，不请求 AI。

## 常见问题

**如何更新？**

安装包版本需要手动更新：关闭使用扩展的网页，将新版解压到原安装目录并替换文件，在 `chrome://extensions` 中点击 Peak Distance 的「重新加载」，再打开或刷新网页。不要先卸载扩展；卸载会删除本机扩展数据。

**为什么没有查词入口？**

安装或更新后先刷新网页，再检查扩展的「网站访问」是否允许当前站点。

**为什么没有中文字幕？**

视频需要有可用字幕，翻译服务也可能受网络或限流影响。可以重试，或主动选择 AI 翻译；失败时会保留英文原文。

**支持哪些视频？**

目前面向 YouTube 常规视频，不支持 Shorts、直播或 Netflix；不采集音频，也不为无字幕视频生成字幕。

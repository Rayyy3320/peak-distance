# M5：上下文 AI 问答

历史阶段方案，仅用于追溯。当前产品约定见 [PRD](../PRD.md)，当前任务见 [ROADMAP](../ROADMAP.md)。本文件中的阶段限制和交付指令不再作为当前任务要求。

## 1. 入口与默认行为

| 入口 | 打开后的内容 |
| --- | --- |
| 共用查词弹窗「继续问」 | 当前来源的对话；引用固定表达、原句、邻近文本与已有释义 |
| 字幕列表某句「问 AI」 | 当前视频的对话；引用固定该句及时间 |
| 侧栏「问答」 | 当前来源的对话；没有显式引用，讨论当前材料 |

- 打开入口只准备本地上下文，不自动发请求。输入框提供“解释这句 / 梳理观点 / 举例说明”起始提示，点击填入问题，发送才调用服务。
- 顶部展示来源标题、材料范围、可移除的引用卡片。移除引用只取消焦点，保留材料背景。视频继续播放不更新已固定引用；用户可从另一句重新带入引用。
- 弹窗转入侧栏时关闭弹窗，沿用现有关闭后的播放恢复规则。问答视图本身不自动暂停或恢复播放。
- 侧栏打开沿用用户点击手势，先调用打开动作，再异步准备材料；冷启动时也能接收待带入的引用。若全屏环境不能展示原生侧栏，保留引用并提示退出全屏后继续。
- 发送后显示准备 / 等待回答状态，收到正文后逐步显示；支持停止。滚动阅读旧消息时不强制拉回底部，提供回到最新回答。

## 2. 内容获取与身份

| 来源 | 会话身份 | 材料 |
| --- | --- | --- |
| YouTube | videoId；不同时间 URL 属于同一对话 | 复用当前轨道的英文字幕列表，带稳定段落 ID、原文、起止毫秒；不等待中文翻译 |
| 普通文章 | 当前 URL，保留查询参数；仅移除普通段落锚点与文本定位片段，保留 hash 路由 | 当前已加载文章正文，保留段落次序与原文 |
| X | 目标帖子的 status ID | 目标帖子的正文；不包含邻近信息流、回复或引用帖正文 |

- 网页提取优先选区所在文章或页面主文章区，排除导航、页脚、编辑区、隐藏内容和扩展 UI。可选用成熟正文提取库，避免维护大量网站规则。
- 首次提取展示简短原文预览和范围。无法确认正文时退回选中片段，标记“选中片段”；不使用整个 body 冒充文章。
- X 详情页可直接进入问答；信息流必须先从目标帖子选词 / 选句，取得对应帖子链接。没有目标帖子时提示先选择内容，不按首页 URL 合并对话。
- 材料仅在打开问答、显式更新材料或带入新引用时获取，不随播放器时间或网页 DOM 持续重建。保存不可变材料快照；新内容与已存快照不同则建立新版本，旧消息引用保持原版本。视频快照补齐现有侧栏状态未携带的 trackId；引用固定到同一材料版本。
- 切标签页 / 站内导航时显示新来源对话，草稿按来源保留。已发送请求固定来源；返回时只更新原对话，不挤占新页面。无可用材料时保留输入草稿，给出选取文字的入口。

## 3. 请求上下文与长内容

- 每次请求包含：语言助手指令、当前材料范围的英文原文、可选引用、当前问题、近期已完成对话。默认中文回答，英语例句保留英文；材料作为被讨论的数据，不作为系统指令。
- 初始正文预算为 48,000 字符（包括段落 ID），属于产品请求上限，不代表模型容量；在代码中集中定义。预算内附上本次提取的完整正文，界面标记“已加载正文”或“当前轨道完整字幕”。
- 超限材料按原文顺序、段落 / 字幕边界分为每段最多 24,000 字符的片段；单个过长段落可按句切分。默认选中包含引用 / 当前播放位置的片段，无焦点则选第一片段。
- 超限时展示片段选择及时间 / 段落范围。切片段后仍在同一对话，每条问题记录当时范围；不提供自动整部总结，不静默只取开头冒充全文。用户问整体时明确当前只覆盖哪一段。
- 历史保留最近至多 6 个完整问答对，合计不超过 12,000 字符；优先保留最近完整对，超限整对移出请求。旧对话仍可查看，可从旧消息再次引用；不自动生成历史摘要。历史消息携带原范围标签，不能被当作当前材料证据。
- 当前问题上限 4,000 字符，超限在输入处提示，不静默裁剪。已有词汇表和其它网页不会自动进入请求。

## 4. 多轮与流式生命周期

- 增加问答专用多轮、流式调用；复用 DeepSeek endpoint、模型、key 与错误分类，不套用查词两行格式或翻译 JSON 格式，不改变既有查词 / 翻译行为。
- background 发起请求，通过侧栏与 background 的长连接传送正文增量；每次请求绑定 sourceKey、材料版本、turnId、requestId。一个来源同一时刻只生成一个回答，另一窗口打开同一来源时订阅该状态。
- 流解析处理网络分块、半行 SSE、多事件合包、最终结束及截断；只展示最终回答正文，不把 reasoning_content 当答案或存入对话。
- 等待首段正文期间显示“正在准备回答”，仍可停止。采用明确超时：60 秒未收到有效流事件或总时长达到 180 秒即中止并显示可重试错误；重试由用户触发，不自动重复计费请求。
- 停止通过 AbortController 取消请求，保留已生成正文并标记“已停止”；失败保留问题与部分正文。重试替换同一回答尝试，不重复追加用户消息。
- 关闭侧栏或切到其它侧栏视图时停止其生成；仅切换浏览器标签页时可继续写入原对话。worker / 连接中断后，已存 streaming 状态恢复为“已中断”，不能一直显示生成中。
- 发送前落库问题与请求归属；正文增量至多每秒检查点保存一次，结束 / 停止 / 错误时立即保存最终状态。只有成功落库才显示已保存；流式中断最多丢失最近一次检查点后的增量。

## 5. 原文引用与保留解释

- 原文块具有快照内唯一 ID。指令要求内容归纳 / 推断引用这些 ID；语法解释可直接引用所选表达。只将当前请求材料中存在的 ID 转为可点击来源，不执行模型生成的任意跳转 URL。
- 视频引用显示时间并跳转原句；网页引用显示原文片段并尝试滚动定位。网页已变化或定位失败时显示保存的原文及来源链接，不假装定位成功。
- 点击视频引用时复用已有 tabId + videoId 校验；原标签页已换视频则打开相应来源时间链接，不操纵新视频。相同 cue 序号在不同轨道 / 快照间不复用身份。
- 回答用纯文本和受控引用链接展示，保留段落、列表换行，不渲染模型 HTML。无依据的解释应注明推测；没有有效引用不伪造来源。
- 每条已完成回答可“保留解释 / 取消保留”；同一对话提供“已保留”筛选，显示回答与当时引用。只标记既有回答，不新建笔记系统、不覆盖词典释义。

## 6. 本地保存

- 每个来源一条连续对话，支持清空当前对话；清空同时删除该对话的材料快照、引用和已保留标记，不影响生词本与原有上下文。明确确认删除范围。
- 在 `blc-learning` 增量新增 `chats` store，按 sourceKey 保存对话、材料快照、问题 / 回答、引用、生成状态、保留标记与时间；同一快照在对话内只存一次，由消息引用。
- 数据写入集中在 background；模型请求等待期间不持有数据库事务。多窗口操作序列化到同一来源，检查 requestId，防止停止 / 清空后旧结果重新写回。
- 重新打开同一内容恢复记录；URL 不变但材料变化时沿用对话并区分材料版本。不开跨内容记忆、聊天分支或自动用户画像。
- 增量升级前后的旧词条、上下文、词形与设置均可读；数据库版本以实现为准，不清库重建。

## 7. 修改落点与顺序

| 落点 | 改动 |
| --- | --- |
| `shared/lookupPopup.ts`、网页 / YouTube 入口 | 继续问入口；固定引用；材料获取；原文定位 |
| `entrypoints/sidepanel/` | 问答视图、流式状态、片段范围、历史与保留解释；不改原三个视图的语义 |
| `shared/messages.ts` 及必要的 chat 模块 | 来源 / 快照 / 请求归属；上下文预算与流事件类型 |
| `entrypoints/background.ts`、`lib/deepseek.ts`、`lib/db.ts` | 问答请求、流转发与取消、对话存储升级 |

顺序：来源快照与数据库 → 双入口和本地恢复 → 单轮流式 / 停止 → 多轮及内容切换 → 引用与保留解释 → 统一验证。只提取实际共用逻辑，任务完成后更新相关文档，不预建检索或 agent 框架。

## 8. 验收

| 检查 | 通过条件 |
| --- | --- |
| 真实主链路 | 普通文章与有英文字幕的视频分别完成“解释一句 → 追问全文观点 → 点击引用回原文 → 保留解释 → 重新打开继续”；使用现有真实 DeepSeek 配置 |
| X 与正文 | 信息流目标帖、帖子详情的同一 status 恢复同一对话；不带入旁边帖子。文章选区附近正文被包含，导航不混入；提取失败显示选区范围 |
| 范围与预算 | 普通材料在预算内完整传入；超长材料可选片段，选中末尾引用时不落到开头；历史裁剪不拆问答对、不伪称仍记得全部历史 |
| 归属 | A 内容请求在途切到 B，回复只进 A；同视频换轨保留旧引用；移除 / 更换引用后新问题使用新焦点，旧消息不变 |
| 流与中断 | 分块流可正确组装中文；停止真正中止网络请求；鉴权 / 限流 / 超时 / 空正文 / 截断可恢复；worker 重启不留永久生成态；重试不重复问题 |
| 引用与保留 | 有效 ID 能回到正确原文；不存在的 ID 不生成跳转；网页变化时可读保存原文；保留 / 取消保留 / 清空的范围正确 |
| 数据兼容 | 旧收藏与 key 保留；重开侧栏、扩展重启后恢复聊天；多窗口与清空后迟到消息不造成重复或复活 |
| 既有功能 | `npm run verify-local`、`npm run render-check` 通过；针对性覆盖上述预算、归属、流解析及迁移；查词、字幕翻译、标记、复习入口回归可用 |

复用已有检查工具与已登录浏览器。真实回答人工核对是否回答问题、引用是否支持对应判断，mock 仅用于时序 / 失败复现。记录实际结果与未通过项，补充 README 用法及 ROADMAP 状态；不将已有 M2–M4 待复验项自动标为通过。

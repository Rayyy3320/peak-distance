# M2–M4：字幕、再次识别与原句复习

历史阶段方案，仅用于追溯。当前产品约定见 [PRD](../PRD.md)，当前任务见 [ROADMAP](../ROADMAP.md)。本文件中的阶段限制和交付指令不再作为当前任务要求。

## 1. 接续与数据

- 从现有实现继续：`shared/subtitleTracker.ts` 管字幕来源，`shared/vocab.ts` / `lib/db.ts` 管词汇，`lib/deepseek.ts` 管服务请求，现有侧栏承载生词本、字幕列表、复习三个视图。
- 从 `entrypoints/web.content.ts` 提取网页与字幕实际共用的查词弹窗，保留置顶、拖动、快照固定、保存反馈。字幕弹窗放入全屏播放器可见的节点，不靠无限增大 z-index 解决全屏。
- 将 `WebSnapshot`、`ContextRecord`、消息及视图贯通为网页 / YouTube 两种来源。视频上下文保存 videoId、轨道身份、字幕起始毫秒；UI 和 URL 的秒数在边界转换。
- 视频去重使用词条 + videoId + 轨道 + 起始时间 + 原文；同一句在视频不同位置分别保存。来源链接生成对应时间参数。
- 兼容已有 `blc-learning` 数据和 key；旧上下文按 web 读取，新增字段用默认值或增量升级。已有词条键和上下文 ID 保持稳定，不清库重建。
- 补齐 `storage.local.setAccessLevel({ accessLevel: 'TRUSTED_CONTEXTS' })`；content script 通过 background 读取所需设置，不读取 key。用虚拟标记验证访问隔离，不输出真实凭据。[Chrome 文档](https://developer.chrome.com/docs/extensions/reference/api/storage)

## 2. M2 — YouTube 学习闭环

### 字幕与翻译

- 仅常规观看页。优先英文人工轨道，其次英文自动轨道；没有英文轨道时明确提示，不把其它语言当英文处理。沿用现有嗅探链路与过期响应判断。
- 使用 video.currentTime 显示当前英文和对应中文。自动字幕先做必要的滚动重复消除与片段合并，保留来源时间；暂停、拖动、倍速变化后按时间重新定位。
- 翻译复用当前 DeepSeek 连接，在 background 发起；先做这一条翻译路径。按当前字幕附近的小批量预取，携带字幕 ID，响应按 ID 对齐。单标签页最多一批在途，不预翻整部视频。
- 译文在当前视频会话内复用，换视频 / 换轨 / 关闭双语时停止旧预取并丢弃旧结果；跳转优先当前窗口。缺失或失败只影响对应译文，保留英文和查词，不循环自动重试。
- 提供双语开关、显示 / 隐藏中文。隐藏中文不继续预取；关闭双语移除扩展字幕并恢复播放器原字幕显示。默认不显示 M0 调试徽标，保留必要诊断入口。

### 查词与保存

- 点击英文词查释义，拖选短语不误触单词查词；复用 M1 弹窗、状态与存储。查词快照固定原句、相邻字幕、来源和时间。
- 查词时暂停正在播放的视频；关闭时只恢复由本次查词暂停且仍是同一视频的播放。原本暂停、用户主动改变播放状态或已换视频时，不自动恢复。
- 保存与译文、释义是否成功无关。保存视频上下文后，生词本来源可回到对应时间；网页已存词在视频查询时读到同一状态。
- 沿用现有与其它扩展共存的获取链路；不修改其它扩展的开关或设置。

检查点：人工 / 自动英文字幕各真实播放一段，完成双语 → 查词 → 保存 → 来源回跳；全屏可查词，切视频无旧字幕、译文或弹窗残留。

## 3. M3 — 再次遇见与逐句控制

### 跨内容识别

- 网页 / X 正文和英文字幕匹配已存单词、短语，展示 saved / learning / known 状态；known 使用低强调样式。匹配使用词边界，短语按完整表达匹配，冲突时最长匹配优先。
- 匹配只读本地词汇索引，不逐词调用 AI。初次处理正文，后续只处理新增 / 变化文本；跳过编辑区、代码、隐藏文本和扩展自身 UI。保留选区、复制、链接及页面事件。
- 保存、状态修改和删除后，已打开网页、视频与侧栏同步；现有 runtime 广播只覆盖扩展页面，需补齐 content script 通知。仅广播学习数据，不广播凭据。
- 设置提供词汇标记开关；关闭后恢复原页面，不留下重复包装或观察器循环。

### 词形关联

- 在用户查词 / 保存时，从同次释义结果取得可选 lemma 和屈折词形，随词条保存明确关联；已有词条在再次查词时补齐，不后台批量调用 AI。
- 精确已存表达优先；别名只映射到一个明确词条，冲突或不确定时保留独立表达。匹配到关联词形后，查询、保存与修改状态都落到同一词条，原文仍保留实际词形。
- 不按简单去后缀规则合并词条，不自动合并派生词。侧栏能查看并移除错误词形关联；删除词条同时清除其关联。
- 明确验证 `constrain / constrained / constraining` 的关联、`constraint` 的独立、`go / went` 的显式关联，以及短语和词边界误匹配。

### 字幕列表与控制

- 侧栏字幕视图展示当前标签页的视频、完整原文列表及已取得的译文；点一句跳转，播放时标出当前句。用户手动滚动后停止强制跟随，提供恢复跟随动作。
- 提供上一句、下一句、重播本句；按钮可用后再绑定同一动作的快捷键。输入框、编辑区和弹窗内不截获快捷键，绑定在 UI 可发现。
- 切换标签页后控制只作用于侧栏当前显示的视频；消息携带 tabId 和 videoId，过期动作不控制其它视频。非视频页显示明确空状态。

检查点：网页保存 → 视频识别、视频保存 → 网页识别均成立；X 动态新增正文可识别；改状态 / 删除实时同步；词形反例不误合并；字幕点击及三种播放动作作用于正确视频。

## 4. M4 — 原句复习

- 侧栏增加复习入口，使用已存 saved / learning 词条及其真实上下文；默认排除 known。展示原句和来源，隐藏释义；支持揭示、下一条、修改状态、返回来源。
- 一次会话按词条遍历，每个词条选一条已有上下文，不重复刷同一词条。揭示前后都不发 AI 请求；无释义时明确显示未保存释义。
- 当前词条被删除或改为 known 后继续下一条；无可复习词条及本轮结束均有明确状态。退出复习返回生词本。
- 网页来源打开原 URL，视频来源定位保存时间；本轮不加 TTS、打分、间隔算法、复习统计或新 review 表。

检查点：从真实收藏进入复习，揭示 / 下一条 / 状态修改 / 返回来源完整可用；已掌握与删除后队列及时更新。

## 5. 一轮执行与统一验收

先贯通来源数据和共用弹窗，完成 M2；再用同一词汇索引完成 M3；最后复用已有上下文完成 M4。修复本轮引入的问题后继续，不因单个界面完成而提前交付。

| 验收面 | 必须证明的结果 |
| --- | --- |
| 工程回归 | typecheck、build、regress、render-check 通过；扩展现有检查覆盖字幕时序 / 翻译归属、视频上下文去重、词形反例、复习队列，不新建一套测试平台 |
| 真实服务 | 使用已配置 key 验证网页与字幕的真实释义，以及人工 / 自动字幕的真实中文翻译；记录视频、轨道、时间与实际显示结果，不记录 key 或完整签名 URL |
| 播放交互 | 正常播放、暂停、跳转、倍速、全屏、站内切换、开关双语、查词恢复播放；全文列表及快捷键控制目标正确 |
| 学习闭环 | 网页 / X ↔ 视频跨内容识别、词形关联、状态同步、上下文历史、来源回跳、原句复习 |
| 持久化 | 更新前已有收藏仍可读；新视频时间与词形关联在扩展 / service worker 重启后保持。完整浏览器重启放在独立测试 profile，保留日常会话与 key |
| 失败归属 | 翻译失败保留英文，旧视频 / 旧轨道 / 旧选区响应不覆盖当前内容；多标签页控制不串页；无字幕和无收藏状态可恢复 |

优先复用已登录 Chrome 和已有自动化入口。需要隔离的存储 / 重启检查使用独立 profile；测试只清理自身创建的数据。阻塞某个验收时记录具体原因，继续其它独立检查，不转交用户重复手工验收。

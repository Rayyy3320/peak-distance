# M11：多语言学习与本地 Markdown 学习库

状态：待实施。2026-10-04。

入口：[ROADMAP](../ROADMAP.md)。M11 替代历史“仅英语／Chrome／中文／无文件夹共享”限制；其余行为沿用 [PRD](../PRD.md)、[ARCHITECTURE](../ARCHITECTURE.md)。

## 1. 目标、范围与完成定义

让用户在同一电脑的 Chrome、Edge 中学习多种语言：就地查词、句段翻译、YouTube 双语字幕、收藏、原句复习和再次遇见标记形成闭环；两浏览器连接同一学习文件夹，Obsidian 中修改的笔记和状态能读回。

- 基础查询默认免账户、免 Key，沿用现有免费在线渠道；没有词典时允许展示明确标注的译文，不承诺每个语言对都有完整词典字段。
- 用户主动打开“无词典结果时自动使用 AI”后，明确查词才允许词典未命中时调用当前 LLM。开关默认关闭。
- 每种源语言可设置一个理解语言，共用于词语解释、句段和字幕译文。界面继续中文。
- 一个生词本，按源语言隔离词条和学习状态，支持语言筛选；网页与视频共享记录。
- 文件夹可位于现有 Obsidian 仓库内。两浏览器分别授权同一目录，无额外常驻程序、云账户或 Obsidian 插件。
- 两浏览器可同时使用；切回浏览器或打开面板时更新即可，不要求跨应用逐字实时协作。
- 共享词汇、原句、字幕句子收藏、学习状态、个人笔记、语言偏好、完整聊天历史及其已提交材料／引用；接受少量辅助元数据。

完成条件：目标语言学习闭环、Chrome／Edge 兼容、Markdown 双向编辑、从学习文件夹恢复已同步内容及旧数据迁移通过第 8 节验收。

范围不扩展到：整页自动翻译、网页段落收藏、句子 SRS、语音识别、离线模型、跨电脑／云盘同步、任意 Obsidian 文档导入、多人编辑、知识图谱或模型供应商迁移。当前网页／PDF／iframe、YouTube 视频类型边界沿用 PRD。

## 3. 多语言行为

### 3.1 首版范围与降级

首版目标清单：英语、中文（简体／繁体目标显示）、日语、韩语、法语、西班牙语、德语、葡萄牙语、意大利语、俄语、阿拉伯语、印地语、孟加拉语、印尼语、越南语、泰语、土耳其语、波兰语、荷兰语、波斯语。

语言标识、服务映射和能力状态集中在代码维护；保留实际字幕轨道标识与语言变体，按服务转换语言代码。

- 每个源语言都要能选区查询／翻译、保存原文和语境、复习、按语言标记；视频有原文字幕时还需支持轨道选择、分词查词和句子收藏。
- 无真实词典的语言仍可完成基础闭环，界面显示译文或 AI 释义，不伪造词性、词形、读音和例句来源。
- 清单外或暂不可识别的内容仍可选区和保存；明确显示待确认语言／当前能力缺项，不按英语处理。
- 服务失败与功能未实现分开记录；某语言的稳定失败不能用合成响应证明“已支持”。不静默缩减目标语言清单。

### 3.2 内容语言与理解语言

- 新安装默认理解语言为简体中文，可按源语言覆盖；不增加全局必选“当前学习语言”。
- 网页按局部内容判断：本次手动指定优先，其次结合选区所在原句与局部语言线索；页面 `lang` 只是线索，不足以覆盖混合语言正文。检测使用不需 Key 的能力，不后台调用 LLM 做识别。
- 视频以用户选中的原文字幕轨道为准。首次沿用当前可用轨道；没有当前轨道时选可用原文轨道并显示语言，同一语言优先人工字幕。允许手动换轨，不强制切英语，也不把平台翻译轨道当原文。
- 单个短词／专名无法确定时，词卡显示“待确认”，允许选择语言再查询。句段可在免费渠道支持时自动检测翻译，但不能把不确定结果永久记成英语。收藏不被语言不确定阻断。
- 修正词卡语言只作用于当前内容，不修改整个网站默认值。保存后纠正语言保留语境和笔记；若与已有词条相遇，复用下文的合并／冲突规则，不清空状态。
- 切换理解语言影响新查询及当前可见译文；历史解释保留其语言和来源，不批量重译。源语言与理解语言相同时，不生成重复字幕译文，词典和学习操作仍可用。
- 独立问答默认使用默认理解语言；附加单一语言材料时可使用该语言偏好，用户明确要求的回答语言优先。混合材料不擅自选一个源语言。

### 3.3 查询路由与 AI 开关

| 结果／动作 | 开关关闭 | 开关开启且 AI 已配置 |
| --- | --- | --- |
| 主动查词，适用词典有结果 | 词典结果 | 词典结果 |
| 没有适用词典，或适用源均明确未命中 | 免费译文 | AI 释义；失败可回退免费译文 |
| 词典网络／限流／解析异常 | 标明故障，可尝试免费译文 | 同左，不把故障当作明确未命中 |
| 悬停预览、页面标记、词汇统计、预取 | 不调用 AI | 不调用 AI |
| 主动句段翻译、常规字幕模式 | 常规翻译链路 | 不受查词开关影响 |
| 点击解释语境，或已有明确 AI 翻译模式 | 沿用明确 AI 动作 | 同左 |

- 开关可以保存，但未配置 AI 时说明需要配置，当前查询继续免费路径；配置 Key 本身不打开开关。此调用授权保存在当前浏览器，不通过学习库替另一浏览器开启。
- 复用现有主／备用词典配置；不适用于语言对的源跳过。无需为每个语言增加一排供应商设置；能力映射由实现管理。
- 词典按源／目标语言对匹配；其它语言的词典内容不能冒充目标语言结果。本轮不增加二次翻译词典解释的链路。
- 主动查词始终保持词典优先；已有免费译文缓存不能绕过尚可用的词典结果。免费翻译沿用现有通道，不假设其能力等同于付费 Cloud Translation API。
- 复用请求去重与取消；从悬停进入点击词卡最多触发一次允许的 AI 请求。关闭开关后取消对应未完成自动兜底，迟到结果不覆盖当前状态。
- 新增 AI 词义结果与词典、普通译文、AI 语境解释可区分；一般释义不能冒充当前原句的语境答案。
- 请求固定源语言、理解语言、原文／语境及 AI 配置快照；缓存和在途身份随这些输入区分，词典缓存不混入其它语言的同形词。
- 翻译请求保留原文大小写与内容，词条规范化不改写翻译输入。替换现有按英文字母占比判定翻译失败的规则；专名或同语输入保持原文不直接判为失败。AI 提示按实际源／目标语言组织，沿用现有供应商协议。

### 3.4 分词、字幕、标记与复习

- 网页和视频共用语言边界逻辑；优先验证浏览器内置分词能力是否足够，再针对实际失败补最小处理。保留拖选词组入口，不建立全语言形态学引擎。
- 保留重音、撇号、连字符和原始显示文本；不能统一去音调或按英语词尾合并。大小写／规范化按语言处理，土耳其语等用例应覆盖。
- 同形异语表达分别保存，词形关联限同一语言且有明确依据；词条稳定 ID 与显示文本／文件名分开。
- 页面标记依据局部语言，无法确定时宁可暂不自动标记；不能把英语已掌握状态套到其它语言同形词。人工选区查询仍可用。
- 原句复习、字幕词次、悬停查词和再次遇见标记采用一致边界。整句／长段落不因“没有空格”就被判定成单词；显式翻译入口适用于所有文字系统。
- 译文链路按目标语言寻找已有字幕，其次平台翻译，再免费逐句回退。沿用时间对齐、AP、暂停恢复、轨道切换取消与语境定位。
- 将面向用户的“英文／中文”固定文案改为实际语言或“原文／译文”；旧设置与已保存中文字幕按兼容迁移读取，不做简单字符串全局替换。
- 生词本初始显示全部语言，记住筛选；复习使用显式选择的单一语言，默认沿用当前单语言筛选。全部视图进入复习时让用户选语言；待确认记录作为独立集合可筛选和复习。

## 4. 本地学习库

### 4.1 连接与保存边界

- 未连接文件夹仍可使用全部学习功能，保持现有本机保存。设置提供“连接学习文件夹”；Chrome／Edge 分别选择同一目录并授权。
- 空目录初始化学习库；已有学习库读取库身份后连接，不覆盖。第一次连接将本机持久记录增量合并进去，重复连接不重复导入。
- 一个浏览器配置文件连接一个学习库。断开不删除文件，待办按库身份保留；连接另一目录时不自动搬入原库内容。
- 目录可以是 Obsidian 仓库中的专用子目录；只管理该范围内已识别的学习文档，忽略 Obsidian 配置、回收站和无关文件。
- 连接后，文件夹承载共享持久资料；IndexedDB 是运行副本、索引及待写入队列，不是另一套独立的冲突裁决来源。
- 收藏／状态等先事务性提交本机并排队写入。只有共享文件及必要元数据成功提交，才显示“已写入学习库”。未成功时显示“已保存在本机，待写入”。
- 打开面板、窗口重新获得焦点／可见以及相关写入前触发读取；更新已打开页面的词汇索引。对同一触发合并执行，只解析变化的受管文件，不在每次悬停扫描库。
- 关闭面板后网页收藏、后台完成的聊天也要能写入，或保留可恢复待办并在下一次活动时自动补写。具体运行上下文由阶段 A 实测决定，不为维持写入要求用户常开一个标签页。

### 4.2 文件组织与最小格式

建议布局如下。语言目录用于整理，不决定记录身份：

```text
学习库/
  词汇/en/...
  词汇/ja/...
  句子/...
  对话/...
  材料/...
  偏好.md
  .peak-distance/...
```

词条格式：

```markdown
---
id: vocab-稳定标识
language: ja
expression: 学ぶ
status: learning
---

# 学ぶ

## 我的笔记
在 Obsidian 或扩展中编辑自己的理解。

## 释义
英语解释及其来源。

## 原句
原句、出处、网页链接或视频位置。
```

- 每个词条／句子／对话一份 Markdown。文件名为可读标题加短 ID，处理本机文件名限制；去重不依赖文件名。
- 正文保留解释语言、结果种类和来源，必要的关联 ID 可由辅助元数据承载。不要把完整数据库 JSON、嵌套属性或大量隐藏标记塞进每份正文。
- `.peak-distance` 保存格式版本、关联、必要修订、删除和冲突信息；不增加完整版本历史。
- 可恢复单位是整个学习文件夹，包括辅助目录；单独复制某篇 Markdown 可阅读，但不承诺完整恢复聊天关系。已确认同步的记录不能依赖某个浏览器私有数据才能恢复。
- `偏好.md` 保存默认理解语言及按源语言覆盖；缺失条目用默认值，设置页与文件双向生效。Key、AI 服务配置、调用开关、未发送草稿、当前窗口／标签页状态、缓存不写入共享库。
- 类型、序列化和校验规则集中在代码；库内附简短使用说明。

### 4.3 Obsidian 双向编辑

| 外部操作 | 扩展行为 |
| --- | --- |
| 修改词条 `status` 或“我的笔记” | 下次读取更新列表、详情、复习及页面标记；扩展也提供简单笔记编辑入口 |
| 给句子／对话补充个人笔记 | 读回笔记；不新增句子学习状态或改变历史消息 |
| 添加自定义属性／其它正文 | 保留原内容；不尝试给任意 Markdown 推断产品语义 |
| 文件改名或在库内移动 | 按稳定 ID 识别，更新关联链接，不重复导入 |
| 删除记录文档 | 成功读取完整目录并排除同 ID 移动后记录删除；旧缓存不能复活记录 |
| 暂时写坏属性、重复 ID、修改历史消息／材料等受管内容 | 保留文件，定位该项问题；暂停该项写回，其它记录继续工作 |

用户可自由编辑个人笔记。源语言／表达纠正由扩展入口处理，保证身份合并；外部直接改这些身份属性时提示到扩展处理，原文件不被重置。状态值采用现有 saved／learning／known，库内说明列出中文含义即可，不做 Obsidian 自定义控件。

写入只更新受管字段／块，保留用户内容与格式；无 ID 的普通笔记不自动导入。

### 4.4 合并与并发

按“上次共同内容、当前文件、本机修改”判断差异；仅文件时间戳不能裁决冲突。

| 变化 | 处理 |
| --- | --- |
| 两边追加不同语境／独立记录 | 合并保留；按稳定标识去重 |
| 笔记变化＋释义追加，或不同字段变化 | 自动合并 |
| 同一字段改成相同结果 | 视为一致 |
| 同一状态改成不同值，或同段笔记被双方修改 | 保留双方，显示该记录的冲突处理；不按时间或“已掌握优先”丢弃一方 |
| 删除遇到未同步修改 | 保留可恢复副本，选择保留或删除后记录决定 |

冲突 UI 只在真实冲突时出现，提供“使用文件版本／使用本机版本”；笔记可复制或编辑合并后保存。无需新增常驻同步中心或三方差异编辑器。解决后其它浏览器应用同一决定。

扩展提交前保留可恢复修改并检查文件变化，提交后确认结果。具体方案由阶段 A 实测选择；浏览器内锁不能作为跨浏览器／Obsidian 互斥证据。并发覆盖无法解决时报告失败用例，不自行增加常驻服务或协同协议。

### 4.5 完整聊天与材料

- 每条历史消息保留角色、文本、次序、时间、完成／停止／失败／中断状态；保留解释标记和现有可用来源信息。材料、引用段落、范围、视频位置与对应轮次共同保存。
- 完整历史是全部已持久化历史，不是请求模型时裁剪后的最近几轮。材料只保存当时实际捕获／提交的范围，不重新联网扩成全文。
- 对话 Markdown 提供顺序阅读和材料链接，个人笔记独立。材料快照不可变，删除单个会话不删除其它会话仍引用的材料；首版可保留未引用材料，不增加自动垃圾回收。
- 每轮生成归发起浏览器所有。本机按现有机制保存流式进度，文件按适当节奏写入，完成／停止／失败时尽快提交；另一浏览器不自动接管、重试或把外部生成状态改成中断。
- 文件写入尚未完成时，另一浏览器只能看到已写入部分；用来源／状态说明，不伪装实时同步。发起浏览器恢复后按自身请求情况处理中断。
- 继续聊天前读取共享新历史。若已经产生两个基于同一旧消息的独立续问，保留为两个可读会话分支，复制共同前缀并记录来源即可，不做分支树编辑器。
- 保留 M10 首次发送才持久化、临时输入关闭／切会话丢弃、模式与标签切换保留的规则。连接和刷新学习库不重建或覆盖当前未发送草稿。

## 5. 迁移与兼容

- 在原 IndexedDB 上增量升级；保留原有记录 ID／关联的可追溯映射和旧版本数据。首次写入学习库后重新读取并核对关联，再确认迁移完成，不通过清库简化实现。
- 有明确轨道语言或可核对词典证据的旧记录按证据归属。只有英文产品定位、ASCII 拼写、旧请求固定 en 等不足以证明原文语言；无法确定的放“待确认”，仍可查看／复习，不自动用于跨语言标记。
- 同一旧词条的语境若实际跨语言，按语境拆分并保留旧身份映射。迁移可继承旧状态以避免丢失用户操作，并标明待确认；新发生的跨语言状态互不联动。
- 两浏览器已有数据按语言身份、语境及稳定消息身份合并，重试迁移不增加副本。ID 相同但内容分歧按冲突处理，不把不同会话仅因标题相同就合并。
- 旧 Key、供应商配置、窗口行为、原文／中文历史结果保持可读。曾共享的记录修改目标语言后不重写历史。
- 旧版本持久化草稿保留本机兼容数据，不作为共享聊天历史或自动发送。
- Chrome 最低版本和 Edge 最低支持版本以真实用到的 API 与阶段 A 结果决定；不为扩大版本范围削弱 M10 关闭语义。构建尽量共用一份，只有实际差异才加分支。

## 6. UI/UX 与 Design DNA

沿用以下 Design DNA／UIUX 依据，按改动范围阅读：

| 文档／实现 | 下游用途 |
| --- | --- |
| [design.md](../../design.md) | 纸感、山海品牌、颜色、字体、间距、窄宽布局、可访问性；视觉主依据 |
| [M8 UI/UX spec](m8-peak-distance-uiux.md) | 统一导航、固定／浮动承载、面板内设置、视频全屏与选区翻译 |
| [M10 交互 spec](m10-chat-and-popup-interactions.md) | 临时编辑、删除按钮、卡外关闭及单层入口 |
| [M7 视频 spec](m7-youtube-learning-workspace.md) | 仅修改视频时阅读：字幕、暂停恢复、AP、词语／句子操作 |
| [PRD](../PRD.md)、[ARCHITECTURE](../ARCHITECTURE.md) | 产品边界、状态和请求归属 |
| `shared/tokens.css`、`theme.css`、`brand.ts` | 复用现有视觉变量与控件，不复制一套新 token |

新增界面保持在现有工作区：

- 设置增加“语言”和“学习库”小节；语言只设默认理解语言、按源语言覆盖、AI 查词兜底开关。库设置提供连接／断开、写入状态和必要的重新授权入口。
- 查词／翻译卡显示可纠正的源语言及目标理解语言；词典、译文、AI 结果来源可辨认。生词本与句子列表增加语言筛选，笔记在现有详情内编辑。
- 视频提供原文轨道选择，中文显隐文案扩展为译文显隐；保留字幕层级、字体、AP 与播放操作位置。
- 复用纸色、轻边框、操作蓝、现有表单／删除交互；不新做语言首页、课程卡片或全局主题。
- 源文和译文分别处理方向与字体回退；RTL 原文局部排版，不翻转中文界面。长词、组合字符、混合文字、窄面板与全屏要可读可操作。
- 正常操作留在面板。仅首次选目录／重新授权若受浏览器上下文限制，可由按钮打开复用设置的独立扩展页，完成后回原工作区；不是新学习页。
- 字段错误定位到相应文件／记录；真实冲突局部处理。正常保存给就近状态，不每次弹框或强制确认。

实现造成的规范变化更新 `design.md`；不重写历史报告。

## 7. 下游实施包与出口

执行层确定函数、schema 和必要依赖；复用现有模块。

并行时按 [三线程分工与开工 Prompt](m11-parallel-development.md) 的文件归属和合同基线执行。

| 阶段 | 最小交付 | 完成证据／后续 |
| --- | --- | --- |
| A：能力验证 | 一份临时学习记录，在真实 Chrome／Edge 授权目录，读写、重启、关闭面板、worker 恢复；与 Obsidian 往返和并发；抽样核实免费通道 | 记录浏览器版本、调用上下文、权限恢复、读写归属及实际并发结果。通过后继续，不再请求例行批准 |
| B：多语言闭环 | 集中语言定义、查询路由、语言身份迁移、字幕／标记／复习和最小 UI | 语言与调用边界用例通过；可独立于文件夹功能交付 |
| C：学习库纵向链路 | 连接 → 保存一个词条 → Obsidian 改笔记／状态 → 第二浏览器读回 → 断开恢复 | 最小格式、权威数据边界和冲突流程成立，再扩展数据类别 |
| D：完整资料与迁移 | 句子、偏好、全部聊天／材料、分叉、已有记录迁移及重建 | 从新浏览器恢复已同步资料；关系、状态和来源核对一致 |
| E：集成验收 | 目标语言覆盖、两浏览器实机、窄宽／RTL、安装说明 | 对照第 8 节报告通过、失败、未测与限制，更新 ROADMAP 和使用文档 |

A 的文件系统分支失败时，不把 C／D 标为完成，不自行添加本地服务；继续不依赖它的 B，并把实测限制及最小选择交回策略层。服务覆盖失败先检查已有免费通道；新增收费依赖或缩减语言承诺需要用户决定。普通实现选择、局部修复和已授权测试由下游完成。

## 8. 验收合同

| 编号 | 场景 | 必须观察到的结果 |
| --- | --- | --- |
| L1 | 每个目标源语言查询词／句；日语→英语、法语→中文，补充一个 RTL 目标 | 实际语言对生效；免费请求证据及结果类型清楚，不能用词典字段缺失冒充整项失败或成功 |
| L2 | 英语／法语 `pain`，日语／中文同形表达，短词不确定 | 不串词条／状态／缓存；不确定可纠正和收藏 |
| L3 | 重音、土耳其语大小写、日语／泰语无空格、阿拉伯／波斯文字 | 分词点击、完整拖选、词次、复习和标记边界一致；无词内错误标记 |
| L4 | AI 开关关／开、未配置、词典命中／未命中／限流、悬停后点击 | 请求计数符合路由表；悬停、标记、预取为零 LLM 调用；主动兜底不重复 |
| L5 | 快速改源／目标语言、换视频／轨道、关闭卡片、切 AI 配置 | 迟到结果不串入当前内容；历史解释及来源保留 |
| L6 | 非英文原文轨道、目标字幕／平台／免费回退、AP、全屏 | 不强切英文；时间对齐、播放与暂停归属符合旧约定 |
| V1 | 两浏览器连接同一目录，重启及 worker 恢复 | 权限／恢复路径真实可用；无需常驻程序／固定打开标签页 |
| V2 | Obsidian 改状态和笔记，扩展追加例句，切回另一浏览器 | 不同字段合并，笔记与自定义内容保留，页面学习标记更新 |
| V3 | 同词并发收藏、同时改状态、删除与修改、改名移动 | 去重；冲突可处理；不把移动判删除；旧客户端不复活删除记录 |
| V4 | 权限撤销／目录失联，期间收藏，恢复后读取 | 本机持久待办保留，恢复重试不重复；未落盘不报已同步 |
| V5 | 断开／换库；一个文件格式错误或同 ID 副本 | 库之间不混数据；该文件问题可定位，不覆盖它或阻断其它记录 |
| C1 | 多轮／超长历史、材料版本、引用、停止／失败／中断、保留解释 | 新浏览器恢复全部持久历史，引用回到对应材料／时间；不只剩模型最近上下文 |
| C2 | 另一浏览器读到生成中会话；两边基于旧历史续问 | 不自动重发／接管；两支各自消息和材料保留 |
| M1 | 旧英语、非英语、未知语言与跨语言同形旧记录迁移两次 | 不清库、不丢语境／状态／聊天；不盲目全标英语；重复运行幂等 |
| U1 | Chrome／Edge 固定、浮动、视频全屏、窄宽界面及 RTL | 与第 6 节依据一致；键盘操作、来源、错误和写入状态可理解 |

验证分层：

- 纯逻辑集中验证语言身份、路由、格式往返、合并和迁移；用贴近失败风险的用例，不为每个属性做镜像测试。
- 浏览器／文件系统用真实临时目录和独立配置文件，测试结束无需改动用户正式库。受控响应验证路由、取消和请求计数；真实服务抽样验证来源与语言，不反复请求全组合。
- 每个目标源语言至少有一个真实免费查询／翻译样本；文字系统、目标语言对和视频链路按上表代表用例验收，不做所有语言对笛卡尔积。视频至少保留英语回归并验证日语与一种非拉丁／RTL 原文场景；无真实材料时明确未测。
- 运行 `npm run verify-local` 及实际受影响的浏览器检查；现有脚本默认可能启动 Edge，报告实际可执行文件和版本。相关检查通过后，仅有新改动／失败才重跑相应部分。
- 下游将证据写到 `docs/specs/m11-verification-report.md`，语言／来源覆盖记录放同一报告，必要原始输出留工具产物。未通过项不能由旧 M6–M10 报告替代，也不因 M11 自动重开无关旧缺口。

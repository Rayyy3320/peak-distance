# 选区查词与添加到对话

状态：已实施。范围、根因与验证见 [验收报告](selection-chat-actions-verification.md)；剩余实机项以报告为准。

## 目标与范围

普通网页、X、YouTube 页面正文（描述 / 评论 / 标题）与字幕（播放器字幕栏、侧栏字幕列表）支持选区直接添加到当前聊天；附加内容可预览；查词容忍标点及漏选字母；长句、段落隐藏查词。

本规格决定本轮行为；其余沿用 [PRD](../PRD.md)。布局沿用 [design.md](../../design.md)，消息与存储边界按需查阅 [ARCHITECTURE](../ARCHITECTURE.md)。

## 选区入口

| 本地分类 | 浮条操作 |
| --- | --- |
| 一个有效词，含词内撇号/连字符 | 查词、添加到对话 SVG |
| 2–5 个有效词，未跨正文块、字幕项或明确句界 | 查词、翻译、添加到对话 SVG |
| 其余句段 | 翻译、添加到对话 SVG |

- 复用语言分词及原文结构，三个入口共享规则；无空格不等于单词，自动折行不等于跨段。短句可落入短语候选，不增加语法识别。无有效查词表达时隐藏查词。
- 网页、X 与 YouTube 页面正文用同一浮条；YouTube 字幕栏内选区走字幕操作条，词卡、翻译卡、浮动面板与字幕栏内的选择不产生页面浮条。
- SVG 为单色线性“对话气泡＋”，tooltip 和可访问名称为“添加到对话”，尺寸及命中区沿用设计规范。
- 点击直接附加并进入当前聊天，成功后聚焦输入框、保留问题草稿；不先查词、不自动发送。沿用固定/浮动、全屏及原生面板用户手势机制。
- 保留字幕悬停、单词点击及暂停/恢复行为；拖选不同时触发单词点击查询。

## 最近选区与查词表达

- 有效阅读选区形成时固定文本、来源、位置和局部上下文。进入面板、原生高亮折叠或字幕重绘不清空候选；新选区覆盖旧候选。
- 候选按标签页和内容身份隔离；导航、切视频或原文轨道后失效。输入框、词卡、聊天正文中的选择不覆盖阅读候选。固定/浮动切换及侧栏字幕切到聊天保留候选。
- 侧栏“附加选区”显示候选摘要，点击使用同一快照；无候选显示原因。候选只临时保留，不写会话历史或学习库。
- 原始选区用于翻译和附加；查词根据原文位置补齐首尾残缺单词，去掉确定在词外的标点，保留内部撇号、连字符及有意义的词尾符号。
- 词卡标题、实际查询、缓存和收藏使用同一有效表达。不修改网页文本；无法定位或原文自身拼错时不猜拼写，不批量改历史词条。

## 附加内容

新 SVG、侧栏“附加选区”、词卡“继续问”共用以下范围：

| 来源 | 材料与焦点 |
| --- | --- |
| 网页/X/YouTube 页面正文 词或短语 | 选区为焦点，所在局部正文块中包含该选区的原句为背景 |
| 网页/X/YouTube 页面正文 句段 | 选区本身 |
| 字幕词或短语 | 选区为焦点，所在原文字幕项为背景，带视频和时间 |
| 跨字幕项 | 实际选择的原文及起始位置，不含译文或控件文字 |
| 词卡继续问 | 当前词卡表达和可靠原句，可带已有释义，不发新查询 |

- 原句按选区位置提取；没有可靠原句就只附加选区，不取 body 开头或其它段落兜底。X 来源绑定被选中的帖子；YouTube 页面正文按当前页面为来源，不绑视频轨道，仅字幕选区带视频与时间。
- 全文通过“附加页面”或“附加视频字幕”显式添加。页面取可识别的已加载正文；X 只取目标帖子；视频取当前原文轨道已获取字幕。菜单按来源显示对应入口。
- 一次一份材料；新附加成功替换当前材料及焦点，重复附加不叠加，焦点变化仍更新。保留草稿和历史快照；失败保留旧材料。
- 已附加内容不随后续选区或播放改变。最新附加、移除或切会话不能被迟到结果覆盖；复用现有身份校验和 M10 临时编辑生命周期。
- 材料正文保持完整，仅 UI 预览可截断；长选区不存入限长的词汇表达字段。沿用现有预算和超预算分段，超限明确提示。

## 附件展示与反馈

- 当前材料只在输入框上方展示：选区显示原文，页面显示标题，默认最多两行；点击原位展开实际材料、上下文、来源及已有释义，长内容有界滚动。
- × 移除材料及焦点，保留问题。去掉顶部重复的材料/引用大块和版本号；保留会话操作与历史引用查看。
- 超预算分段选择放在附件区，预览和发送范围一致。
- 空选区、提取/通信失败、后台拒绝均有就近反馈；失败信息保留到重试或下一次操作。材料附加成功与面板打开成功分别判断，写入失败不能提示已附加。

## 实现边界与入口

本地容错、分类、提取和附加零 LLM。后续查询沿用现有词典、翻译和用户显式开启的 AI 兜底。复用当前消息、分词、材料快照及临时编辑；保持历史材料和学习库序列化兼容。本轮不新增多附件、语法模型、状态框架或通用选区系统。

| 改动 | 入口 |
| --- | --- |
| 网页/X 选区、原句与直接添加 | entrypoints/web.content.ts |
| 两处字幕选择 | entrypoints/youtube.content.ts、entrypoints/sidepanel/main.ts、shared/selection.ts |
| 分词及查词表达 | shared/tokenize.ts、shared/lookupPopup.ts |
| 附加菜单与预览 | entrypoints/sidepanel/chatView.ts、index.html、style.css |
| 材料与会话、面板打开 | shared/chat.ts、shared/messages.ts、lib/chatService.ts、lib/chatWorkspace.ts、lib/panelService.ts |

分别定位“附加选区”和“附加页面”的实际失败点；无材料提示不能直接当作选区丢失的证据。完成本范围实现、验证及必要文档更新，普通实现选择自行决定。

## 验收与交付

| 场景 | 通过条件 |
| --- | --- |
| 普通网页/X 直接添加、侧栏附加、继续问 | 三入口范围一致；不先查词也能添加；焦点折叠后候选仍可用，替换选区后附件更新 |
| 播放器/侧栏字幕单词、短语和跨项选择 | 原文、视频、时间对应；无点击误触和暂停/恢复退化 |
| learning 选 learnin；外围引号/逗号；don't、well-known、词尾符号 | 查询及收藏表达正确；原选区未被改写；无法定位不猜 |
| take off、in terms of；超过 5 词或跨段；中日文无空格 | 符合分类表，长句/段落无查词，翻译和附加输入完整 |
| 独立附加页面/视频字幕、超预算材料 | 提取范围可核对，X 不串帖子，发送实际选定分段 |
| 重复附加、连续 A→B、移除/切会话、来源导航 | 不重复、不串来源、不回填旧结果，草稿及历史保留 |
| 通信/后台失败、面板打开失败 | 反馈准确，旧材料和问题保留，未写入不报成功 |
| 固定/浮动切换、窄面板、长内容 | 预览、展开、移除可用，输入区不被挤出，无重复材料区 |
| 历史与调用 | 首次发送前无持久会话，旧引用可读，本地处理/附加零 LLM |

运行现有类型、构建和相关回归检查；用少量边界用例和真实入口验证表中行为。检查通过后，仅为新修改、失败或未解决问题重跑。交付实际根因、改动及验证结果；实机不可用时单列未验证项。

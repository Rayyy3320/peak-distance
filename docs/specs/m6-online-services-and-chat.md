# M6：在线服务与独立问答

状态：主体实现与集成已完成，统一验收尚未全部通过；见 [验收报告](m6-verification-report.md)。产品行为以 [PRD](../PRD.md) 为准。本轮完成免 key 在线词典、常规字幕翻译、显式 AI 兜底、独立问答，以及直接影响这些链路的缓存 / 复习修正。

## 1. 先验证来源

在实际扩展请求环境验证下列候选，结果记入 [REFERENCES](../REFERENCES.md) 的接入记录；验证后继续实现，不停在调研结论。

| 能力 | 候选与选取 |
| --- | --- |
| 在线词典 | 剑桥英汉、有道、牛津学习词典；参考 Saladict 的请求与解析。选择一个有中文义项的主来源和一个可用备用，其余仅保留原站入口 |
| YouTube 中文 | 可用中文字幕轨道、平台 tlang 翻译；复用 yt-dual-subs 对应实现 |
| 通用翻译 | yt-dual-subs 的免 key Google 翻译路径；同时用于字幕和自由短语 |

- 词典验证 run、bank、went、take off、in spite of、a surprisingly good result 和一个不存在的词。区分完整词条、词形跳转、短语义项、无词条与网络失败；记录实际显示内容，不以 HTTP 200 代替成功。
- 视频验证人工 / 自动英文字幕，并检查中文轨道与平台翻译的时间对应。已有上游代码只是候选，不等于当前可用。
- 不要求词典 key，不引入本地词库或付费词典 API。遇访问验证提供原站入口，不能以验证页当释义。
- 某候选不可用则换下一候选；都不可用时保留未完成项并继续其它独立工作，不以 AI 或外链冒充内联词典交付。

## 2. 在线查词与保存

- 共用查词弹窗默认走“有效缓存 → 首选词典 → 一个备用词典”。仅网络失败或无完整词条时尝试备用；用户主动指定另一词典时直接查它。禁止全来源并发查询。
- 首屏显示表达、词性、简明义项、一条例句及词典署名；有真实音标 / 音频才展示。其它义项可展开，支持换词典、查看原文、收藏、已掌握、解释语境。
- 固定短语必须命中完整表达或明确短语义项。只有 take 的一般词条不算 take off 成功；自由短语没有词条后可走常规翻译，结果标为“翻译”。不靠 LLM 判断应该走哪条路径。
- 词形使用来源返回的原形 / 屈折信息；歧义时保留候选，不猜测归并。停止默认 AI 词形生成与自动并入；旧关联保留且可移除。
- “解释语境”明确调用一次 AI，按当前固定原句展示结果，基础词典结果继续保留；常规查询成功、失败、等待与收藏动作本身均不调用 AI。
- 查询无结果显示“未查到该表达”，提供换词典 / AI 解释；服务失败显示“暂时无法查询”，提供重试 / 查看原文。收藏始终可用。
- 词典义项、普通译文、AI 语境解释分别保留类型、来源与原句归属。收藏默认保存当前可见基础结果；用户选中某义项时保存该义项，AI 解释不能覆盖词典内容。
- 旧 definition 按已有上下文释义兼容读取，不虚构词典来源。先收藏后结果到达时只补写原上下文，不能复活已删除记录或写入新选区。
- 复习优先取同一上下文的原句与语境解释；缺解释时保留空态。一般词典义项可另列，不从其它原句拿解释填补。

## 3. 翻译方式与 AI 选择

- 默认“常规”；已配置 DeepSeek key 不等于选择 AI。播放器提供常规 / AI 切换，设置页保存默认方式；本视频临时切换不改全局默认。
- 常规路径依次复用可用中文字幕、平台翻译、通用免费翻译。只有缺失或失败部分进入下一来源，不重新翻译已成功内容。
- 独立字幕轨道按时间范围对齐；平台配对结果在 ASR 合并时一起转换；句子翻译按稳定字幕 ID 对齐，不按两组数组下标硬配。
- 常规路径不可用显示“翻译暂不可用”，仅提供“用 AI 翻译”“重试”；英文继续显示。点击“用 AI 翻译”即确认，作用于当前 tab + videoId，换视频 / 标签页关闭后失效，不再弹第二次确认。
- 用户明确选择 AI 模式后可直接按当前窗口小批量翻译。模型与供应商信息放在设置页，不常驻播放器。
- background 按实际用户动作或有效模式决定是否走 AI；普通网络错误、空结果、词形缺失不能自动触发 AI。使用 AI 时复用现有凭据。
- 隐藏中文、关闭双语、换视频 / 轨道 / 服务后停止旧任务；能取消的在途请求执行 abort，已返回的旧结果不得覆盖新会话。关闭双语恢复播放器原字幕显示。
- 记住双语与中文显隐偏好；仅开关显示不清缓存。失败不按播放轮询不断重试，重试按钮只重试当前需要的结果。

## 4. 缓存与设置

- 缓存已成功的在线查询 / 翻译，不下载全量词库；在同一扩展会话内跨弹窗、显示开关和页面刷新可复用，设置明确容量上限。可以用现有存储能力，不单独搭建缓存服务。
- 词典缓存隔离来源、查询表达和语言；普通翻译隔离来源、模型配置、语言与文本；AI 语境解释还须包含原句及邻近语境。空结果 / 错误不作为永久成功缓存。
- 多次请求同一结果可复用在途任务；同一消费者关闭不取消其它消费者仍需要的任务。服务切换不能读到旧服务结果并伪装为新来源。
- 设置只增加实际接入的首选 / 备用词典、常规翻译来源、默认翻译方式与显示偏好；字典无 key 输入，无动态插件安装。保留现有 AI key 和词汇标记设置。
- 网络 HTML 在有 DOM 的扩展上下文或经过验证的解析器中提取字段；service worker 没有 DOMParser。保留来源链接，不把远端 HTML 整段注入 UI。

## 5. 独立问答

- 侧栏问答始终提供输入框、“新对话”和历史；无材料、中文页面、不支持注入的页面及空标签页也能发送普通问题。无 key 时提供设置入口并保留草稿。
- 会话 ID 与 sourceKey 解耦；同一内容可有多个会话。标题默认取首条问题的简短文本，不额外调用 AI 起名。
- 当前会话不随浏览器标签页改变；只有用户选历史 / 新建 / 明确继续某会话才切换。窗口内记住活动会话，草稿按会话保存。
- 输入框提供“附加页面 / 附加选区 / 附加视频字幕”。一次附加一份主要材料，可带句级引用；替换材料影响后续问题，旧消息保留原快照。
- “继续问”和字幕“问 AI”把快照带入当前活动会话；没有活动会话时新建，先展示引用与范围，发送才请求。无需先读页面才能创建会话。
- 移除材料后不再发送其原文、引用或以该材料为依据的问答轮次；旧记录仍可查看。请求只包含无材料历史和当前材料对应的历史，避免隐藏材料继续进入上下文。
- 保留现有流式、停止、重试、有效引用回跳、保留解释和长内容片段机制。无材料回答不生成材料引用；同名块 ID 必须按每条消息的快照解析。
- 切到生词本 / 字幕 / 复习或换浏览器标签页时继续生成，问答标签显示生成状态；请求不再因 UI 取消订阅而中止。关闭侧栏窗口可停止该窗口发起且无其它窗口关注的请求；显式“停止”立即取消。
- 历史始终可进入，支持删除单会话；清空只影响当前会话。停止、删除后迟到增量不能写回。

## 7. 顺序与可选并行

1. 集成人核对现有实现，确定最小结果类型、会话 ID / 材料边界和存储接口；源码差异以现有代码为准。
2. 来源验证可以与独立问答并行。验证通过后，按下表分工；若单人执行则按词典 → 翻译 → 问答顺序完成。

| 工作线 | 独立修改范围 |
| --- | --- |
| A 在线词典 | 词典请求 / 解析模块、lookupPopup；来源验证结果与相关用例 |
| B 常规翻译 | 常规翻译模块、YouTube 入口、cues；对齐与取消用例 |
| C 独立问答 | chat 纯逻辑、chatService、chatView；会话 / 材料用例 |
| 集成人 | shared/messages、shared/vocab、db、background、设置、侧栏主入口、复习修正及现有测试脚本 |

共享文件由集成人修改；工作线通过已约定的普通函数 / 消息交付，不同时改数据库和消息联合类型。局部检查通过即可交集成，不各自启动一套完整浏览器验收。集成人完成迁移和端到端验证后交付，不在模块完成时提前停止。

## 8. 验收

| 验收面 | 通过条件 |
| --- | --- |
| 默认零 LLM | 冷缓存、无 AI key 下完成单词、短语和字幕查询；词典 / 翻译超时、无结果、受限时也无 LLM 网络请求；已配 key 的默认模式同样成立 |
| 明确选择 AI | 当前表达 AI 解释可用；字幕点击确认后才开始 AI，换视频恢复默认；主动选择默认 AI 模式正确持久化 |
| 词典真实结果 | 主 / 备用来源的单词、变形、短语义项在弹窗内可读；来源与原文链接正确；take 的普通义项不能冒充 take off；自由短语显示普通译文 |
| 字幕与缓存 | 人工 / 自动英文字幕各实际观看；独立中文轨道和句子译文对齐；反复开关、刷新命中已有成功结果；快速换轨 / 服务与取消无旧结果覆盖 |
| 学习数据 | 不同语境不共用 AI 解释；先收藏后结果到达写回原上下文；复习不拿另一原句的解释填空；已有标记与词形仍可用 |
| 自由问答 | 空白 / 中文 / 不可注入页面可新建并发送；切标签页不切会话；附加 / 移除 / 替换材料改变实际请求；同内容两个会话互不覆盖 |
| 问答生命周期 | 切侧栏视图不中止；停止 / 重试 / 删除 / 重启状态正确；首次发送不误报中断，句级引用带入、跨会话引用清理通过 |
| 迁移 | 旧学习记录、聊天、草稿、引用、保留解释和 key 完整；重启后读回；重复迁移不新增副本 |

使用网络请求记录证明“零 LLM”，不以界面文案代替。复用 verify-local、render-check 和真实浏览器检查，仅补来源解析、路由、对齐、取消、迁移的针对性用例；外部来源与真实 AI 至少各验证一次。对历史报告中的网页标记问题做实际页面回归。

隔离 profile 用于重启 / 迁移测试，仅清理本次测试数据；扩展重载后核实目标站点访问权限。来源验证、构建和验收全部完成后更新 ROADMAP，并保留精简结果记录；未通过项明确列出，不重复追加逐工具日志。

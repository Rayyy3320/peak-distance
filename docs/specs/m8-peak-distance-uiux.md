# M8：Peak Distance UI/UX 重构

状态：已实现，验证与实机边界见 [M8 验收报告](m8-verification-report.md)。视觉依据为 [design.md](../../design.md)，产品约定见 [PRD](../PRD.md)。本 spec 替代 M7 的面板承载与设置入口方案；未改变的字幕获取、暂停恢复、AP、收藏、缓存与问答行为继续沿用。

## 1. 交付范围

- 全部现有界面统一为 Peak Distance：扩展侧栏、页内面板、查词／翻译浮层、字幕控件、生词本、句子、复习、问答、设置和扩展图标。
- 固定模式使用 Chrome 原生侧栏；浮动模式使用当前网页内的面板，覆盖现有普通网页、X 和 YouTube 常规视频。
- 设置在面板内完成，不因日常设置操作新开标签页。复用已有扩展页面资源，不增加独立学习页或其它用户页面。
- 修复全屏字幕背景遮挡和句子／段落选区翻译。翻译方向沿用英文到简体中文。
- 不新增整页自动翻译、段落旁常驻按钮、句子 SRS、账号、同步或新的翻译供应商。

## 2. 导航与承载

### 统一导航

主导航为「当前内容」「生词本」「AI 问答」，品牌区提供模式切换、设置和关闭。

| 入口 | 内容 |
| --- | --- |
| 当前内容 · 网页／X | 当前选区的查词／翻译；附加材料继续复用已有问答入口，不自动读取并翻译全文 |
| 当前内容 · YouTube | 字幕、词语、已保存；保留时间定位、全部词汇与出现位置 |
| 生词本 | 词语／句子切换；从词语列表进入已有原句复习 |
| AI 问答 | 原有独立会话、历史、材料、引用、草稿与停止生成 |
| 设置 | 面板内设置视图；返回后恢复原模块和滚动位置 |

- 字幕「已保存」仍默认本视频；查看全部转入生词本对应类别，不创建第二份记录。
- 模式切换不切模块、不清空选区快照、问答草稿、引用、会话或复习进度，不重新发送请求。
- 选区查词／翻译仍可就地完成，不强迫先打开主面板。

### 固定与浮动

- 首次使用默认固定模式；用户主动切换后记住模式偏好。扩展按钮与播放器学习入口进入同一工作区。
- 固定侧栏使用现有扩展入口；浏览器管理其宽度与左右位置，不再同时展开旧 YouTube 页内固定侧栏。
- 浮动面板可通过标题区拖动并关闭；初始位于页面右侧安全区域，不新增调整大小功能。窗口变化时保持标题和关闭按钮可见。
- 单个窗口的当前页面只保留一个活动主面板。迁移到目标容器成功后再收起原容器；失败时保留原内容并显示可执行的切换入口。
- 用户切换标签页时，当前内容跟随活动页面；会话不自动切换，选区结果标明原来源。已保存状态共用现有数据库。
- 无页面注入权限或浏览器受限页面保留原生侧栏，说明页内浮动不可用，不申请全站权限来绕过限制。

### YouTube 全屏

- 普通／剧场模式继续在视频下方显示字幕；本轮不改成画面内字幕。
- 全屏保留原生视频全屏。工作区按需在全屏节点内以浮动面板显示，默认不自动展开；退出全屏恢复之前的模式偏好与模块状态。
- 全屏时「固定」操作不退出视频全屏；提示退出全屏后可使用固定侧栏。
- 若退出全屏后的浏览器限制不允许自动重开原生侧栏，保留工作状态，并提供用户点击的恢复入口。
- 关闭面板不退出全屏、不改变播放状态。字幕、词卡避让面板和原生控制条；关闭后释放占用区域。

## 3. 面板内设置

- 保留现有设置与有效值，普通显示开关继续即时保存；API key 保留明确的保存／清除动作，成功或失败在对应控件旁反馈。
- 设置修改不重建当前会话；返回当前内容后按实际生效的设置显示。
- 旧 options 地址继续兼容并复用同一设置组件；正常应用入口不再调用另开设置页。
- 两种模式都能在面板内完成凭据设置。key 输入与保存位于受信任的扩展源上下文；页内 Shadow DOM 本身不是凭据隔离边界。
- 不把已保存 key 下发给内容脚本、宿主页面或普通设置快照。保存后清空输入，仅显示已配置状态。

## 4. 选区翻译

### 入口与结果

- 保留单词／短语查词；对多词选区同时提供明确的「翻译」动作。用户选择「翻译」时直接调用常规翻译，不等待词典查询，不依赖词典是否报错，也不调用 AI。
- 支持普通网页、X 和插件字幕中的英文句子／段落选区；保持现有输入框、PDF、跨域 iframe 等范围限制。
- 支持超过旧选区入口上限的段落；完整保留原文、大小写、换行及来源。新请求边界在代码统一定义，入口、消息、缓存与服务使用同一边界。
- 超出支持范围时保留入口并明确提示缩小选区，不静默隐藏、截断或只翻译开头。
- 结果在选区附近的浮层呈现，显示原文、译文、来源、复制、重试与关闭；长内容内部滚动。缺词典义项时不能将译文包装成词典结果。
- 继续问复用已有明确 AI 入口；不因翻译成功、失败、超时或已配置 key 自动调用 AI。
- 段落翻译本身不写入单词词库，不增加新的段落收藏／复习能力；原有词语和字幕整句收藏继续可用。
- 请求绑定选区快照；换选区、关闭、导航后旧结果不得覆盖新内容。错误时保留完整原文与重试操作。

### 已知代码证据

| 位置 | 实施前需覆盖的问题 |
| --- | --- |
| `entrypoints/web.content.ts` 的 `evaluateSelection` | 长选区直接返回空，导致入口消失 |
| `entrypoints/youtube.content.ts` 的 `selectionPhraseInBar` | 选区被截断后传递 |
| `entrypoints/background.ts` 的 `parseSnapshot` | 查词载荷按表达长度截断，不能直接用作段落翻译契约 |
| `lib/lookupService.ts` 的 `lookupOnline` | 常规翻译依赖词典全部返回未命中，网络失败会阻断回退 |

尚未收到用户失败原文／网址；以上是代码确认的问题，不认定已复现全部实机失败。

## 5. 全屏字幕可读性

- 保留当前字幕字体、字号选项和中英层级；只调整背景承载、文字轮廓和必要间距。
- 去除横向大面积高不透明底板；底色尽量贴合字幕文本，使用轻量阴影／描边保证亮画面可读。
- 默认底色从 25% 不透明度起验证；这是实现起点，不表示已完成实机校准。不新增透明度设置项。
- 普通／剧场模式的独立字幕区不随全屏背景调整而失去可读性。

## 6. 实施顺序与出口

1. 先验证现有扩展资源在两种容器中复用、设置凭据隔离、浏览器侧栏切换和全屏承载；通过后接统一导航。
2. 修复选区翻译和全屏字幕遮挡，覆盖正常、失败、取消与过期结果。
3. 按 design.md 接入视觉基线与素材，覆盖全部现有模块和真实内容状态。
4. 检查改动涉及的逻辑、构建与真实浏览器交互；记录通过项、未通过项和证据。无素材时可完成结构，但不标记品牌视觉验收通过。

| 验收面 | 通过条件 |
| --- | --- |
| 固定／浮动 | 网页、X、YouTube 均可切换；内容与草稿连续，无重复主面板；受限页保留可用入口 |
| 设置 | 两种模式内均可保存显示设置和 key，不新开标签页；宿主页面和内容脚本收不到 key |
| 全屏 | 进入／退出／关闭／恢复正常；字幕与控制条不冲突，明亮、黑暗、快速变化画面均可读且背景不大面积遮挡 |
| 选区 | 单词查词、固定短语、完整句子、超过旧上限的多句段落、含换行段落均有正确入口与完整结果；超限有提示 |
| 请求 | 词典断网不阻断主动翻译；翻译失败可重试；上述常规路径无 AI 请求；旧结果不串选区 |
| 学习与问答 | 收藏／已掌握、原句复习、播放定位、悬停暂停／恢复、AP、问答持续生成和历史恢复不回退 |
| 视觉与可访问性 | 面板内容宽 320 / 400 / 600px、浏览器 100% / 125% 缩放检查；无横向溢出，键盘可操作，长文本与空／加载／错误状态完整 |
| 品牌 | 实际界面的名称、图标、排版、纸感和插画一致；无临时素材、海报截图或假功能按钮 |

复用现有 `verify-local`、`render-check` 与受影响的 M6/M7 检查，按新行为更新过时断言。真实侧栏、全屏、凭据隔离和网络归因必须使用实际扩展验证，不以模拟 runtime 或静态截图代替。

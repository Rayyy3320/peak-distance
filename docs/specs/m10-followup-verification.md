# M10 后续修复记录

2026-10-03，版本 0.4.2。依据 [后续诊断](m10-followup-diagnosis.md) 实施已确认的删除反馈与异常收尾，并补齐浮动工作区诊断和恢复防护。用户补充：白屏约一分钟偶发，不要求继续死磕，优先其余问题。白屏直接触发原因仍未确认。

## 已完成

- 问答消息同步抛错、返回 Promise rejection、通信错误及空响应统一返回局部失败。删除失败保留记录、恢复按钮并显示行内错误，不自动重试删除。日志只记录动作类型与固定技术原因，不输出问题或材料。
- 删除成功显示“已删除一个对话”，历史显示总数。不同 ID 的同名旧空记录删除后，总数及数据库恰好减少一条，轮询不会补建；未用过滤代替删除。
- 浮动外壳不再永久信任第一次 ready。使用 Chrome 提供的当前扩展文档身份定向读取工作区加载／就绪状态；文档变化、无工作区响应和初始化失败均可诊断。仅可见时检查可用性，不自动重载。
- 加载和重试共用就绪期限，失败后外壳显示明确提示及重试按钮；重试再次失败后仍可继续操作。诊断只保存阶段、文档身份、版本和固定失败原因等必要元数据。
- iframe 自然失效不再作为用户关闭而丢弃临时编辑，恢复新文档后沿用窗口级临时状态。明确关闭面板、承载网页或窗口仍按原约定丢弃；承载网页的关闭消息匹配外壳身份，避免旧网页事件影响新外壳。

Chrome 文档身份与定向检查依据：[Runtime API](https://developer.chrome.com/docs/extensions/reference/api/runtime)。未读取跨源 iframe 的内部文档，也未建立通用页面消息代理。

# M6 验收记录（2026-10-02）

主体实现与集成已完成，**尚未满足全部交付条件**：真实 YouTube 人工 / 自动字幕观看与已登录 Chrome 的最终构建、站点权限仍待复核。

## 实现

- 有道 / 剑桥顺序查词，指定来源直接查询；完整表达无词条后自由短语走 Google 普通翻译。弹窗显示义项、例句、来源、原站入口，支持选择义项及显式 AI 语境解释。
- 基础结果与 AI 解释按类型分别归属原上下文；停止默认 AI 词形生成及新关联自动并入。旧词形和旧释义兼容读取，复习不借另一原句的解释。
- 中文字幕、平台 tlang、Google 依次补缺；独立轨道按时间交集对齐，平台配对先按时间匹配再随 ASR 合并。播放器支持当前视频临时常规 / AI 切换、显示偏好和取消。
- 成功缓存使用现有 `storage.session`，隔离来源、语言、文本及 AI 模型 / 语境；共享在途任务在最后一个消费者取消后 abort。容量和文本总量有上限，显示开关不清缓存。
- 独立会话、可选材料、窗口内活动会话、按会话草稿和历史删除。移除材料后请求排除其原文、引用和材料问答；旧消息引用按自己的快照来源解析。
- 数据库增量迁移旧聊天，保留词条键、上下文 ID、正文、草稿、快照、引用、保留标记和已有 key。旧聊天 store 保留作兼容备份，不清库重建。

产品扩展的真实请求结果：

- 冷缓存、无 key 时，`book` 查询及 `It is sunny today.` 普通翻译成功；已有 key 时，`run`、`bank`、`went`、`take off`、`in spite of` 内联词典成功。`a surprisingly good result` 显示普通翻译「出奇的好结果」，不存在的词返回 `not-found`。
- 显式切换剑桥返回完整 `take off` 短语；重复查询未新增请求。字幕输入 ID 37 的译文仍返回 ID 37。
- 记录 background 请求尝试与浏览器实际网络事件。常规查询 / 翻译成功、无词条和受控网络失败阶段均为零 LLM 请求；后续显式 AI 解释才向 DeepSeek 发起真实请求，返回 bank 在存钱原句中的银行含义。记录不包含请求头或 key。
- 真实 Wikipedia 页面保存后出现正文标记，刷新后恢复，关闭标记后移除包装并保留原文。历史报告中的网页标记问题在本轮该页面已复核。

隔离环境中的请求和状态检查：

- 真实扩展 UI 在空白标签页、中文测试页面和不可注入的浏览器内部页均可发送普通问题，不自动附加页面；无 key 保留草稿与设置入口。
- 可控 SSE 检查首次发送、切视图持续生成、切标签页不切会话、停止、重试、清空防迟到写回。同一材料的两个会话互不覆盖。
- 检查实际组装的模型请求：移除材料后不再包含其原文、引用及相关问答；旧回答与新材料都使用 p1 时，旧引用仍显示原快照。
- 旧 schema 样例迁移后保留上下文 ID、词形、聊天正文、草稿、引用及保留标记；重启恢复状态与 key，重复打开无重复迁移记录。
- 受控 YouTube 页面运行实际 MV3 路由：常规失败显示“用 AI 翻译”而不调用 LLM，点击一次才调用；不改变全局默认，换视频失效。设置页的默认 AI 方式和缓存容量可保存并读回。

临时 profile 只复制用户授权的本扩展设置，迁移样例和测试记录均在隔离数据库中创建。未修改日常 Chrome 学习数据库。最终验收脚本已删除当次临时 profile；截图与无凭据网络记录保存在本机 `.upstream/m6/`。早期调试 profile 的递归清理被自动审批拒绝（仅返回 `blocked by policy`）；已改用扩展 storage API 清除并核实其中复制的 key，目录内仅保留隔离调试数据。

## 实测截图反馈后的修正（0.1.1）

用户截图显示双语已开启但只有英文，以及旧版查词“解释失败：网络错误”文案。只读核对日常 Chrome 配置，加载路径为本项目 `.output/chrome-mv3`，三个来源域名权限均已授予；截图缺少当前构建的翻译方式与词典控件，提示页面可能仍在运行旧脚本。本次未把这一推断当作已验证的网络故障根因。

- 播放器右上角常驻“本视频翻译方式”选择器和“设置”；关闭双语时仍可访问。全局默认方式在独立设置页，侧栏也提供常驻入口，设置页底部显示版本。
- 补齐中文等待状态，以及无法连接扩展时的刷新提示；请求失败保留英文和恢复动作，避免只有英文而没有任何请求反馈。
- 类型检查、构建与逻辑回归通过；更新后的渲染检查 54 项通过，覆盖选择器作用范围、关闭双语后的入口、中文等待与失败反馈。
- 0.1.1 在隔离 Edge MV3、同机代理、无 AI key 下真实请求：`jelly fugu` → 普通翻译「果冻河豚」；`a reservation or buy a plane ticket. And` → 中文译文，原字幕 ID 12 保持不变。侧栏设置按钮确实打开独立设置页，显示常规 / AI（LLM）两个选项及版本 0.1.1。截图：本机 `.upstream/m6/options-followup.png`。

这些结果验证新构建与相同输入的服务链路；日常 Chrome 中该视频的实际播放、轨道对齐和刷新后效果仍需复核，不据此关闭前述真实视频验收缺口。

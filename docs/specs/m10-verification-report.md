# M10 验收记录

2026-10-03，构建版本 0.4.1。执行范围以 [M10 spec](m10-chat-and-popup-interactions.md) 为准；本地验收通过，用户 Chrome 实机出口保留。

## 实现

- 活动读取和新建不再写入空会话。窗口级临时编辑保存输入、材料与引用，首次发送在一个 IndexedDB 事务提交会话、材料、首问和回答占位；失败保留输入。旧数据迁移及历史快照保持完整。
- 新建、切换、关闭使用窗口操作身份和编辑身份拦截旧响应；提交期间新增的编辑继续保留。模块、标签及固定／浮动／全屏移交保留临时内容；明确关闭丢弃。Chrome 最低版本更新为 142，以使用真实 `sidePanel.onClosed` 事件，移交造成的程序性关闭另有标记。
- 历史行复用 DOM 节点，轮询不重置确认。NativeDelete 局部 DOM 实现接入删除及清空，确认后收起、等待期间禁用，失败就近提示。清空和删除当前会话均回到未保存空态，不影响生词本。
- 选区入口取消内部常驻底色与边框，旧选区开卡后保持隐藏。词卡和选区翻译卡外部点击关闭并继续原操作；自有 iframe 使用现有消息传递发生时间，迟到关闭不影响新卡。

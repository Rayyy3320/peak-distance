## 实现与简化

- 普通模式字幕移到画面下方，提供字号选择；悬停显示就地简明词卡和快速标记，点击展开、同词再点收起。复用原词典 / 翻译 / AI 与保存逻辑，网页弹窗保留原流程。
- 默认折叠的页内侧栏包含字幕、全部词语及次数 / 位置、已保存。词语和整条字幕分别保存，共享原有词汇学习状态；全局句子入口复用扩展学习页面。
- AP 默认关闭，按字幕显示结束点暂停一次；重播可重置，跳转不补暂停。词卡关闭不恢复 AP 或用户保持的暂停。
- 本视频翻译方式与 AP 存在扩展会话存储；字幕请求直接携带确认的方式。后台不再因内存丢失回退到全局 AI。
- 数据库只增量增加句子 store，不迁移或重写旧词汇 / 会话。没有新增依赖、通用状态机、虚拟列表或后台句子回填。
- 全屏使用右侧临时抽屉；全屏期间保留播放器的 DOM 祖先，避免展开过普通侧栏后进入全屏时被浏览器强制退出。

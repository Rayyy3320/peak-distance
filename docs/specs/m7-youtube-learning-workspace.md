# M7：YouTube 学习界面与播放交互

状态：主体实现与集成完成，0.2.1 已完成本轮已登录 Chrome 界面修复验收；见 [M7 验收报告](m7-verification-report.md)。采用现有模块的最小改动，不新增通用框架；当前进度与 M6 剩余验收见 [ROADMAP](../ROADMAP.md)。产品约定见 [PRD](../PRD.md)，已有请求、缓存与问答规则沿用 [M6 spec](m6-online-services-and-chat.md)。

## 1. 目标与已确认范围

用户实测反馈：字幕偏小；查词需要点击后移视到右上角；翻译开关不易发现；视频右上角常驻控件遮挡内容；缺少页内学习侧栏。另有字幕显示双语但没有中文、自由短语查询网络失败的反馈，需要在真实环境复核，不能仅凭截图判定原因。

代码检查确认 `background.ts` 的本视频翻译选择只存在 `subtitleModes` 内存 Map 中，缺失时会读取全局默认。后台重启可能导致界面显示“常规”而请求使用 AI；M7 已修复此缺陷并完成 worker 停止 / 恢复检查，证据见验收报告。

| 项目 | 确认后的行为 |
| --- | --- |
| 字幕 | 普通 / 剧场模式放在视频画面下方，增大可读区域；全屏留在播放器内部 |
| 悬停 | 词语旁显示简明释义，可快速收藏 / 标记已掌握；悬停时暂停 |
| 点击 | 就地展开同一张词卡；再次点击同一个词收起 |
| 侧栏 | 页内侧栏，默认折叠，可展开 / 收起；包含字幕、词语、已保存 |
| 词语页 | 当前视频全部英文词汇，显示出现次数、释义与字幕位置 |
| 已保存 | 同时支持词语与整句字幕；默认本视频，可查看全部和进入已有复习 |
| 全屏 | 保持原生视频全屏；侧栏为临时覆盖右侧的抽屉 |
| AP | 每句结束自动暂停，默认关闭，可独立开启 |
| 控件 | 主要入口移到播放器底部控制区，随原生控件显隐 |

Language Reactor 截图用于交互参考。交付范围以本 spec 为准，不承诺其全部功能。本轮覆盖桌面 Chrome 的 YouTube 常规视频；不扩展 Shorts、直播或其它视频平台，不新增音频采集、ASR、云服务、完整 SRS、词频等级、自动短语挖掘或导出系统。普通网页 / X 保持原有学习流程。

## 2. 布局、字幕与入口

### 2.1 字幕区域

- 普通 / 剧场模式在视频下方提供独立字幕区域；英文为主行，中文为次行。该区域不覆盖视频内容，不与标题、原生控制条重叠。
- 默认字号明显大于当前小浮层，随可用宽度调整；提供小 / 标准 / 大字号选择，作为持久化显示偏好。英文与中文保持清楚的层级，长句可换行，不能省略正在学习的文本。
- 全屏字幕放在播放器底部安全区域；原生控制条出现时避让。打开右侧抽屉时，字幕和新开的词卡优先利用左侧剩余区域，不被抽屉裁掉；不缩放或裁剪全屏视频本体。
- 字幕区至少能区分：读取中、无可用英文字幕、译文加载中、译文失败、中文已隐藏。双语已开启但中文缺失时不得无提示地只留英文。
- 译文失败保留原文，提供重试和明确的“用 AI 翻译”；不能自动切 AI。重试成功后只替换对应字幕项，不能显示上一句的中文。
- 双语关闭时恢复原生字幕的正常使用；重新开启时避免本插件与原生字幕重复叠放。保留用户原有字幕显隐意图，不在卸载本插件界面后留下样式覆盖。

### 2.2 底部入口与设置

- 播放器底部原生控制区增加有可访问名称的“学习”入口，点击打开紧凑菜单，随原生控件显隐。菜单打开或键盘焦点位于菜单内时不能突然隐藏。
- 菜单提供：展开 / 收起学习侧栏、双语开关、中文显隐、本视频翻译方式（常规 / AI）、字号、AP 和打开设置。替换现有视频右上角常驻控件。
- 本视频方式与设置中的“默认翻译方式”明确区分；视频内切换不修改全局默认。播放器不出现 key、供应商或模型配置。
- 侧栏标题区保留关闭与设置入口；已有浏览器侧面板 / 设置入口继续可用，不要求先打开视频才能找到设置。
- 按钮可用键盘操作，有焦点样式与状态名称。输入框、菜单和词卡内的操作不误触 YouTube 播放快捷键。Esc 优先关闭本插件最上层浮层，不主动调用退出全屏。

### 2.3 侧栏布局生命周期

- 新视频默认折叠。普通 / 剧场模式展开后，侧栏位于视频学习区域右侧并分配布局空间，视频保持原比例。窄窗口空间不足时将面板排在字幕区域下方，不挤出不可用的视频宽度或横向滚动条。
- 全屏使用播放器内部的右侧临时抽屉，可独立关闭；进入全屏时抽屉默认关闭，退出后恢复进入前的普通 / 剧场侧栏展开状态。
- 抽屉关闭后释放遮挡和焦点；保留原生视频全屏状态。切换布局不重复挂载字幕、菜单或监听器。
- 切换视频、离开观看页时清理旧词卡、旧字幕和页面布局改动；迟到结果不得把旧视频面板重新显示出来。

## 3. 词语悬停、展开与学习状态

### 3.1 同一张就地词卡

- 英文字幕和侧栏字幕使用相同交互：短暂悬停后显示紧凑词卡，包含表达、简明义项 / 翻译、来源、收藏与已掌握。加载与失败时也能标记，标记成功有即时反馈。
- 卡片贴近触发词，优先向上展开；遇边界翻转并限制在当前可见区域。鼠标从词移入卡片不关闭；离开词与卡片后短暂延迟关闭，避免经过间隙时闪烁。
- 点击词语直接展开并固定当前词卡，显示完整词典内容、固定原句、换词典 / 原站入口和显式 AI 语境解释；长内容在卡片内部滚动。基础义项与 AI 解释保持区分。
- 再次点击同一触发词关闭词卡；鼠标仍在该词上时不立即重新弹出，离开后重新进入才恢复悬停。点击其它词切换卡片；外部点击、关闭按钮或 Esc 关闭。
- 展开期间仅悬停其它词不抢走当前详情；用户点击其它词才切换。选中文字时不误开单词卡，沿用短语查词入口与完整表达查询规则。
- 键盘聚焦词语时可获得同等信息与标记操作，Enter 展开、Esc 关闭后焦点回到触发词；不要求用户必须使用鼠标悬停。
- 卡片固定表达、字幕项、轨道、视频与时间快照。播放继续后不把当前正在播放的句子塞进旧词卡；旧请求不能覆盖新词、已关闭卡片或新视频。
- 复用现有缓存与查询去重，不因鼠标移动并发查询整句全部词，不预查整部视频词典。自由短语未命中词典时沿用常规翻译，不冒充词条。

### 3.2 暂停与恢复

| 事件 | 播放行为 |
| --- | --- |
| 正在播放时出现悬停词卡 | 由插件暂停，并记录恢复资格 |
| 原本已暂停时出现词卡 | 保持暂停，关闭时不自动播放 |
| 鼠标进入卡片、在词之间切换或展开详情 | 保持当前暂停，不反复播放 / 暂停 |
| 离开悬停卡或关闭详情 | 仅当暂停由本次查词造成、仍是同一视频且没有其它暂停原因时恢复 |
| 用户手动播放 / 暂停、跳转或更换视频 | 撤销原查词恢复资格；手动播放后本次悬停不立即再次暂停 |
| AP 已要求暂停 | 查词卡关闭不得解除 AP 暂停 |

不能仅根据 `video.paused` 判断是否应恢复。插件自动恢复不能覆盖用户操作，页面失去目标播放器时也不能对新视频执行旧的恢复动作。

## 4. 页内侧栏

### 4.1 字幕页

- 展示当前选定英文轨道经现有规范化后的字幕列表；可用中文显示在对应原文下方，遵守中文显隐设置。译文请求沿用播放附近的有限预取，列表显示已取得的译文，跳转后补齐当前项，不因展开侧栏翻译全片。
- 当前字幕高亮并自动跟随。用户主动滚动后停止跟随，显示“回到当前句”；点击后恢复。切换页签不使列表无故跳回顶部。
- 行内提供时间定位、收藏整句和“问 AI”。点击时间跳转；词语点击用于查词，不同时触发整行跳转。保留上一句 / 重播 / 下一句及已有快捷键。
- “问 AI”沿用已有带材料问答流程，携带所选字幕与来源；打开入口不自动发送问题，不新增第二套会话存储。
- 无字幕和读取失败分别显示原因与可执行操作；不能把空列表显示为读取完成。长视频列表滚动保持响应，避免一次挂载所有复杂词卡。

### 4.2 词语页

- 从本视频当前英文轨道的规范化字幕本地提取全部英文词汇，包括常用词和专名；显示词面、出现次数、共享学习状态。默认按首次出现排序。
- 大小写等价的词面合并计数，保留可读原词；纯标点和纯数字不列为词。沿用现有分词规则，不为统计猜测原形、自动合并派生词或调用 AI。
- 次数统计真实词次：同一字幕里出现两次计两次；ASR 滚动扩展造成的重复先通过已有字幕规范化消除。同一字幕位置在位置列表中仅列一次。
- 点击词条显示与字幕共用的详情，并列出出现位置和对应原句。默认以首次出现为语境，点击其它位置可选定该次语境；时间按钮负责跳转，不能一开详情就改变播放位置。
- 字幕、词语页、已保存与浏览器生词本共享 saved / learning / known。已有明确词形关联继续使用；新增统计本身不创建学习记录或词形关联。
- 换轨道后重算当前列表，不混入其它轨道的词频；换视频清理列表。若字幕未完整取得，不标称“本视频全部”，应说明实际覆盖范围。

### 4.3 已保存页与整句收藏

- 默认显示本视频记录，可区分词语 / 短语和整句字幕；词语记录显示本视频对应原句和时间，状态修改反映到共享词库。
- “整句字幕”在本轮指一条实际显示的字幕项，可能不是语法完整句。与重播和 AP 使用同一单位，不额外调用 AI 做断句。
- 收藏整句保存英文原文、当时可用的中文及来源、视频 / 轨道标识、标题 / 链接、开始时间与字幕范围。译文未到达或失败仍可收藏；收藏操作不触发翻译或 AI。
- 同一视频、轨道、位置和原文重复收藏不新增；相同文本出现在不同时间分别保留。显示已收藏状态，支持取消；取消后迟到结果不能复活记录。
- 整句收藏不把整句塞入单词词库。删除句子收藏不删除从该句保存的词，删除词也不删除句子收藏。
- “查看全部”复用现有扩展学习记录入口并补齐全局句子列表，可按原来源返回视频；“复习”沿用现有词语原句复习。句子本轮支持查看和回放，不引入新的句子排期 / SRS。
- 关闭侧栏、刷新、重启浏览器后收藏仍在。视频 / 轨道不可访问时仍可阅读保存快照，不展示其它来源的译文来填空。

## 5. AP：逐条字幕结束自动暂停

- AP 是独立开关，默认关闭；本轮为当前视频的会话选项。同一标签页刷新保留，切换视频恢复关闭，不修改双语或翻译方式。关闭双语显示不隐式修改 AP；菜单始终能看到 AP 当前状态。
- 以规范化后实际显示的字幕项为单位。在自然向前播放越过本条显示结束边界时暂停；相邻字幕重叠时，以下一条开始替代更晚的结束时间，避免已经显示下一条再暂停上一条。
- 每次经过一条字幕只自动暂停一次。用户继续播放后可进入下一条，不能在同一边界立即再次暂停；主动重播该条可重新触发。拖动 / 跳转不对跳过的字幕补暂停。
- 句间空隙在前一句结束时暂停，不能等到下一句开始。支持播放速度变化、最后一条字幕和连续无间隔字幕；缺字幕时禁用 AP 并说明原因。
- AP 与查词暂停共用明确的恢复条件。查词先暂停时不能仅按墙钟时间触发 AP；到达 AP 边界同时打开词卡时以 AP 暂停为准。关闭 AP 不自动播放已经暂停的视频。
- 使用媒体时间判断边界，并验证实际停点；不能依赖粗粒度事件导致明显吞掉下一句。精度与实现采用的调度方式在验收报告记录，不在这里预先承诺未经验证的毫秒值。

## 6. 翻译方式的会话一致性

优先修复后台内存丢失导致的模式回退。每个标签页只保存当前视频的模式和 AP 开关到 `storage.session`；同视频刷新读取，换视频初始化，关闭标签页删除。无需额外的状态管理框架。

- 翻译请求直接携带界面已确认的方式，后台只按该方式路由，缺失时拒绝请求，不回退全局 AI。设置写入成功才更新界面，切换期间暂停新的翻译调度。
- 全局默认只用于新视频初始化。复用现有取消与过期结果检查；同一页短时间切换按顺序处理，不另建握手版本协议。
- 常规路径及失败重试不调用 LLM；key 配置不代表选择 AI。
- 会话存储跨 worker 重启保留，扩展重载和浏览器重启后重新初始化，见 [Chrome 官方文档](https://developer.chrome.com/docs/extensions/reference/api/storage#storage_areas)。

## 7. 数据、复用与改动边界

| 现有入口 | 本轮职责 |
| --- | --- |
| `entrypoints/youtube.content.ts` | 字幕布局、底部入口、页内侧栏、卡片锚点和播放交互 |
| `shared/lookupPopup.ts` | 复用查词内容 / 学习动作，提供视频就地卡片所需支持；网页 / X 不回归 |
| `shared/cues.ts` | 复用字幕规范化、定位、时间对齐；只补必要的词次 / AP 纯逻辑 |
| `entrypoints/background.ts`、`shared/messages.ts` | 有效方式恢复与校验、字幕路由、取消和数据消息 |
| `lib/db.ts`、`shared/vocab.ts` | 必要的句子收藏实体与兼容迁移，词汇记录沿用现有语义 |
| `entrypoints/sidepanel/main.ts`、设置入口 | 复用查看全部 / 复习 / 问答；补显示偏好与易发现的入口 |

- 不提前创建整套接口框架或通用播放器适配系统。先复用现有查询、字幕和会话能力，只拆出同时被多个界面实际使用的逻辑。
- 新增句子收藏只做所需数据库增量迁移；旧词汇、上下文、词形关联、会话和草稿保持可读。升级中断后可安全重试，不以清库作为升级路径。
- 学习状态变更同步到已打开的页面 / 面板；无论从哪个入口收藏，同一记录的去重与上下文归属一致。
- 视频切换、轨道切换、查询关闭、消费者取消沿用原取消约定；不因为页内侧栏关闭而取消浏览器侧面板正在进行的独立问答。
- 不通过修改用户浏览器个人配置、安装额外扩展或引入新服务完成此界面改造。测试所需环境问题如实记录，不把隔离测试写成日常 Chrome 实测通过。

## 8. 实施与必要验收

1. 修复模式恢复与请求方式；完成字幕布局、底部入口和就地词卡。
2. 接入侧栏、词频和句子收藏；完成 AP，与已有暂停 / 恢复规则配合。
3. 统一构建、集中浏览器验收，修复发现的问题，更新文档。

实现与测试都保持简单：复用现有 DOM、查询、数据库及检查脚本；不引入虚拟列表、通用状态机或全量组合测试。长列表先使用普通轻量行，仅出现实际性能问题时再优化。句子保存当时快照，不新增后台回填任务。

必要检查只保留以下几组，同一浏览器会话尽量一并完成：

| 检查 | 必须确认 |
| --- | --- |
| 工程 | 类型检查、构建和现有纯逻辑回归；仅补模式选择、AP 边界、词次统计等关键新增逻辑的少量断言 |
| 主要交互 | 真实播放器的普通 / 剧场 / 全屏布局，悬停→标记→展开→关闭，侧栏三页、定位和跟随；查看一次窄窗口与长句 |
